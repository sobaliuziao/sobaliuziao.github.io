Description

本题是一道交互题。

给定 nnn，你需要猜测一个长度为 nnn 的排列 ppp（即 ppp 包含所有 111 到 nnn 的整数各一次）。已知 ppp 满足 p1<p2p_1<p_2p1​<p2​。

当然，你可以进行询问，每次询问你需要给定三个互不相同的整数 a,b,ca,b,ca,b,c，交互器会返回 ∣pa−pb∣,∣pb−pc∣,∣pc−pa∣|p_a-p_b|,|p_b-p_c|,|p_c-p_a|∣pa​−pb​∣,∣pb​−pc​∣,∣pc​−pa​∣ 这三个数中第二小的数。

请在 2×n+4202\times n+4202×n+420 次询问内求出整个排列 ppp。TTT 组数据。

交互格式如下：

  • 首先你需要读入整数 TTT 表示数据组数。接下来对于每组数据：
  • 首先读入一个整数 nnn 表示排列长度。如果你希望询问，按照 ? a b c 的格式输出，你将收到 ∣pa−pb∣,∣pb−pc∣,∣pc−pa∣|p_a-p_b|,|p_b-p_c|,|p_c-p_a|∣pa​−pb​∣,∣pb​−pc​∣,∣pc​−pa​∣ 中第二小的数。你需要保证 1≤a,b,c≤n1\leq a,b,c\leq n1≤a,b,c≤n，且 a,b,ca,b,ca,b,c 互不相同。请注意，如果你的询问不合法，或者你的询问次数过多，交互器会给出 -1 的结果，此时你需要立即停止程序，否则可能会得到任意的评测结果。如果你希望回答，按照 ! p_1 p_2 ... p_n 的格式输出。如果你的回答正确，交互器会给出 1 的结果，此时你需要直接进行下一组数据（如果有的话），否则交互器会给出 -1 的结果，同样的你需要立刻结束程序。

注意刷新缓冲区。

1≤T≤103,20≤n,∑n≤1051\leq T\leq10^3,20\leq n,\sum n\leq10^51≤T≤103,20≤n,∑n≤105。

Solution

考虑怎么一一确定每个数。

注意到如果已经直到 111 和 222 或 n−1n-1n−1 和 nnn 的位置之后，再通过 n−2n-2n−2 次操作就能确定每个数了。

同时我们如果只知道边上的两个数，但不知道是 1,21,21,2 还是 n−1,nn-1,nn−1,n，也是可以做的。因为可以先把边上的数当作 1,21,21,2 确定出整个排列，如果 p1>p2p_1>p_2p1​>p2​ 则让 pi←n−pi+1p_i\leftarrow n-p_i+1pi​←n−pi​+1，否则不变。

现在问题转化为怎么找到边上的两个数。

有个不显然的观察是对于一对距离不长的 (a,b)(a,b)(a,b)，与它们距离最大的两个点一定在边界上。结论是 b−a+1≤n−43b-a+1\leq\frac{n-4}{3}b−a+1≤3n−4​ 时就是对的。

找到长度不超过 n−43\frac{n-4}{3}3n−4​ 的点对是简单的，可以一直随，直到随到权值 ≤n−46\leq\frac{n-4}{6}≤6n−4​ 的 (a,b,c)(a,b,c)(a,b,c) 即可。单次随到的概率是 19\frac{1}{9}91​，420420420 次一定能随到。
