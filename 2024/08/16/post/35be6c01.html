P8518 [IOI2021] 分糖果 题解

Description

Khong 阿姨正在给附近一所学校的学生准备 nnn 盒糖果。盒子的编号分别为 000 到 n−1n - 1n−1，开始时盒子都为空。第 iii 个盒子 (0≤i≤n−1)(0 \leq i \leq n - 1)(0≤i≤n−1) 至多可以容纳 c[i]c[i]c[i] 块糖果（容量为 c[i]c[i]c[i]）。

Khong 阿姨花了 qqq 天时间准备糖果盒。在第 jjj 天 (0≤j≤q−1)(0 \leq j \leq q - 1)(0≤j≤q−1)，她根据三个整数 l[j]l[j]l[j]、 r[j]r[j]r[j] 和 v[j]v[j]v[j] 执行操作，其中 0≤l[j]≤r[j]≤n−10 \leq l[j] \leq r[j] \leq n - 10≤l[j]≤r[j]≤n−1 且 v[j]≠0v[j] \neq 0v[j]=0。对于每个编号满足 l[j]≤k≤r[j]l[j] \leq k \leq r[j]l[j]≤k≤r[j] 的盒子 kkk：

  • 如果 v[j]>0v[j] > 0v[j]>0，Khong 阿姨将糖果一块接一块地放入第 kkk 个盒子，直到她正好放了 v[j]v[j]v[j] 块糖果或者该盒子已满。也就是说，如果该盒子在这次操作之前已有 ppp 块糖果，那么在这次操作之后盒子将有 min⁡(c[k],p+v[j])\min(c[k], p + v[j])min(c[k],p+v[j]) 块糖果。

  • 如果 v[j]<0v[j] < 0v[j]<0，Khong 阿姨将糖果一块接一块地从第 kkk 个盒子取出，直到她正好从盒子中取出 −v[j]-v[j]−v[j] 块糖果或者该盒子已空。也就是说，如果该盒子在这次操作之前已有 ppp 块糖果，那么在这次操作之后盒子将有 max⁡(0,p+v[j])\max(0, p + v[j])max(0,p+v[j]) 块糖果。

你的任务是求出 qqq 天之后每个盒子中糖果的数量。

约束条件

  • 1≤n≤2000001 \le n \le 200 0001≤n≤200000

  • 1≤q≤2000001 \le q \le 200 0001≤q≤200000

  • 1≤c[i]≤1091 \le c[i] \le 10 ^ 91≤c[i]≤109 （对所有 0≤i≤n−10 \le i \le n - 10≤i≤n−1）

  • 0≤l[j]≤r[j]≤n−10 \le l[j] \le r[j] \le n - 10≤l[j]≤r[j]≤n−1（对所有 0≤j≤q−10 \le j \le q - 10≤j≤q−1）

  • −109≤v[j]≤109−10 ^ 9 \le v[j] \le 10 ^ 9−109≤v[j]≤109 , v[j]≠0v[j] ≠ 0v[j]=0（对所有 0≤j≤q−10 \le j \le q - 10≤j≤q−1）

Solution

不妨设 aia_iai​ 表示当前 iii 的糖果数量，那么每次操作就是让 ai←max⁡(min⁡(ai+v,ci),0)a_i\leftarrow\max\left(\min\left(a_i+v,c_i\right),0\right)ai​←max(min(ai​+v,ci​),0)，容易发现可以扫描线然后维护一个关于时间轴的线段树。

如果取 min 和 max 中只有一种是很好做的，就是这题，但是两个放在一起就不好做了。

容易发现只要找到最小的后缀 [p,q][p,q][p,q] 使得这个后缀同时存在 min 和 max，那么 [p+1,q][p+1,q][p+1,q] 就只有一种 min 或者 max 了，所以确定 ppp 时刻的值就可以通过 [p+1,q][p+1,q][p+1,q] 的操作得出答案。

考虑如何找到 ppp。

观察可知如果 [p,q][p,q][p,q] 前缀和的极差 ≥ci\geq c_i≥ci​ 就一定同时存在 max 和 min，并且如果极差 <ci<c_i<ci​ 就一定不会同时存在 max 和 min，所以只要在线段树上二分即可。

时间复杂度：O((n+q)log⁡n)O\left((n+q)\log n\right)O((n+q)logn)。
