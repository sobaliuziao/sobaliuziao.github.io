P6109 [Ynoi2009] rprmq1 题解

Description

有一个 n×nn \times nn×n 的矩阵 aaa，初始全是 000，有 mmm 次修改操作和 qqq 次查询操作，先进行所有修改操作，然后进行所有查询操作。

一次修改操作会给出 l1,l2,r1,r2,xl_1,l_2,r_1,r_2,xl1​,l2​,r1​,r2​,x，代表把所有满足 l1≤i≤r1l_1 \le i \le r_1l1​≤i≤r1​ 且 l2≤j≤r2l_2 \le j \le r_2l2​≤j≤r2​ 的 ai,ja_{i,j}ai,j​ 元素加上一个值 xxx。

一次查询操作会给出 l1,l2,r1,r2l_1,l_2,r_1,r_2l1​,l2​,r1​,r2​，代表查询所有满足 l1≤i≤r1l_1 \le i \le r_1l1​≤i≤r1​ 且 l2≤j≤r2l_2 \le j \le r_2l2​≤j≤r2​ 的 ai,ja_{i,j}ai,j​ 元素的最大值。

1≤n,m≤5×1041\leq n,m\leq 5\times 10^41≤n,m≤5×104，1≤q≤5×1051\leq q \leq 5\times 10^51≤q≤5×105，1≤x≤21474836471\leq x\leq 21474836471≤x≤2147483647，1≤l1≤r1≤n1\leq l_1\leq r_1\leq n1≤l1​≤r1​≤n，1≤l2≤r2≤n1\leq l_2\leq r_2\leq n1≤l2​≤r2​≤n。

Solution

容易发现可以扫描线，但是直接做的话查询时需要维护任意一段时刻内的区间最大值，这显然是做不了的。

但是如果所有的查询 l1l_1l1​ 均相等的话就可以从小到大枚举修改操作和查询的 r1r_1r1​，这样只需要通过区间加、历史最大值线段树维护当前所有操作的区间历史最大值。

这可以启发我们进行类似猫树分治的做法，从浅到深枚举线段树的每一层，找到所有横跨当前层不同节点的询问放在当前层做，剩下的放到更深层做。

由于横跨当前层不同节点的询问 [l1,r1][l_1,r_1][l1​,r1​] 一定只跨过两个节点，所以这两个节点可以把它切割成 [l1,k][l_1,k][l1​,k] 和 [k+1,r1][k+1,r_1][k+1,r1​]，对于 [k+1,r1][k+1,r_1][k+1,r1​] 这部分只需要维护一个历史最大值线段树，然后从小到大做修改操作，在每个线段树节点的开头重置历史最大值为当前最大值即可。[l1,k][l_1,k][l1​,k] 的部分同理。

时间复杂度：O(nlog⁡2n+qlog⁡n)O(n\log^2n+q\log n)O(nlog2n+qlogn)。
