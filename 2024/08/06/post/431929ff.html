CF571E Geometric Progressions 题解

Description

  • 给定 nnn 以及 nnn 个正整数对 ai,bia_i, b_iai​,bi​。
  • 第 iii 对 ai,bia_i, b_iai​,bi​ 确定了一个序列 {ai,aibi,aibi2,aibi3,…}\{a_i, a_i b_i, a_i b_i^2, a_i b_i^3, \ldots \}{ai​,ai​bi​,ai​bi2​,ai​bi3​,…}。
  • 询问最小的在 nnn 个序列中都有出现的数，或者判断不存在。
  • n≤100n \le 100n≤100，ai,bi≤109a_i, b_i \le {10}^9ai​,bi​≤109，答案对 109+7{10}^9 + 7109+7 取模。

Solution

设答案为 kkk，注意到答案很大，考虑分解质因数，设 cntp(x)cnt_p(x)cntp​(x) 表示 xxx 的质因数分解有多少个 ppp，每次合并两个集合。

合并时有 333 种情况：空集、只有一个数的集合、有无穷个数的集合。

考虑如何合并。设最终的数可以表示为 aibikia_ib_i^{k_i}ai​biki​​，那么一定满足 cntp(ai)+kicntp(bi)=cntp(aj)+kjcntp(bj)cnt_p(a_i)+k_icnt_p(b_i)=cnt_p(a_j)+k_jcnt_p(b_j)cntp​(ai​)+ki​cntp​(bi​)=cntp​(aj​)+kj​cntp​(bj​)。对于所有 ppp，如果 cntp(bi)cnt_p(b_i)cntp​(bi​) 和 cntp(bj)cnt_p(b_j)cntp​(bj​) 都为 000，就只用判断 cntp(ai)cnt_p(a_i)cntp​(ai​) 是否等于 cntp(aj)cnt_p(a_j)cntp​(aj​)。

如果 cntp(bi)cnt_p(b_i)cntp​(bi​) 和 cntp(bj)cnt_p(b_j)cntp​(bj​) 只有一个 000，那么就可以唯一确定 kkk 了，求出来然后判断即可。

如果都不是 000，那么一定为关于 kik_iki​ 和 kjk_jkj​ 的不定方程，如果有 ≥2\geq 2≥2 种不同的方程就能唯一确定 kkk。否则就可以通过 exgcd 把 (ai,bi)(a_i,b_i)(ai​,bi​) 和 (aj,bj)(a_j,b_j)(aj​,bj​) 合并，设 xxx 为 kik_iki​ 的最小正整数解，结果就为 (aibix,∏plcm{cntp(bi),cntp(bj)})\left(a_ib_i^x,\prod p^{\text{lcm}{\left\{cnt_p(b_i),cnt_p(b_j)\right\}}}\right)(ai​bix​,∏plcm{cntp​(bi​),cntp​(bj​)})。

这里由于 cntp(bi)≤30cnt_p(b_i)\leq 30cntp​(bi​)≤30，所以所有 cntcntcnt 的 lcm 不会爆 long long，对于乘法用 int128 即可。
