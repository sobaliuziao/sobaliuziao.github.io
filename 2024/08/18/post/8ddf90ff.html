P9530 [JOISC2022] 鱼 2 题解

Description

JOI 君有 NNN 条鱼，编号为 1,2,…,N1,2,\dots,N1,2,…,N。第 iii (1≤i≤N)(1 \le i \le N)(1≤i≤N) 条鱼的大小为 AiA_iAi​。

当我们养鱼的时候，需要注意如下的一个事实：如果有两条鱼离得很近，那么随着时间的流逝，可能会有其中一条吃掉另一条。其中，两条鱼离得很近，当且仅当它们中间没有鱼。
更具体地，如果鱼 xxx 的大小不小于鱼 yyy 的大小，且鱼 x,yx,yx,y 离得很近，那么 xxx 可以吃掉 yyy，且 xxx 的大小变为原来 x,yx,yx,y 的大小之和。如果 x,yx,yx,y 一样大，那么 xxx 吃掉 yyy 或 yyy 吃掉 xxx 都可能发生。

JOI 君会养 QQQ 天鱼。为了消磨时光，他会进行如下的思想实验。在第 jjj 天 (1≤j≤Q)(1 \le j \le Q)(1≤j≤Q)，JOI 君会进行如下行动中的一个：

  • 第一类：JOI 君给鱼 XjX_jXj​ 吃了某些秘制的食物。这会将鱼 XjX_jXj​ 的大小变为 YjY_jYj​。

  • 第二类：JOI 君将编号在区间 [Lj,Rj][L_j,R_j][Lj​,Rj​] 内的鱼单独拿出来，并进行以下实验：
    JOI 君将鱼 Lj,Lj+1,…,RjL_j,L_j+1,\dots,R_jLj​,Lj​+1,…,Rj​ 从左到右依次放在一个鱼缸中。由于鱼们具有如上所述的特点，最后只有一条鱼会存活。存活的这条鱼的编号取决于在哪些时刻哪些鱼吃掉了哪些鱼。JOI 君想知道可能成为最后存活者的鱼的条数。在实验中，鱼的编号不会改变，也不能有两条鱼同时吃掉同一条鱼。

请写一个程序，对于给定的 JOI 君的鱼和实验的信息，计算每个第二类行动的答案来让 JOI 君能够证明或证伪自己的观点。注意这只是思想实验，并没有任何鱼真的被吃掉。

【数据范围】

对于所有数据，满足：

  • 1≤N,Q≤100 0001 \le N,Q \le 100\,0001≤N,Q≤100000。
  • 1≤Ai≤1091 \le A_i \le 10^91≤Ai​≤109 (1≤i≤N)(1\le i\le N)(1≤i≤N)。
  • Tj∈{1,2}T_j \in \{1,2\}Tj​∈{1,2}。
  • 1≤Xj≤N1 \le X_j \le N1≤Xj​≤N (1≤j≤Q)(1\le j\le Q)(1≤j≤Q)。
  • 1≤Yj≤1091 \le Y_j \le 10^91≤Yj​≤109。
  • 1≤Lj≤Rj≤N1 \le L_j \le R_j \le N1≤Lj​≤Rj​≤N (1≤j≤Q)(1 \le j \le Q)(1≤j≤Q)。

Solution

先假设询问区间为 [1,n][1,n][1,n]。

首先直接判断一条鱼 xxx 是否有解是不好做的，考虑判断是否无解。

容易发现如果存在一个区间 [l,r][l,r][l,r]，满足 l<x<rl<x<rl<x<r 并且 suml+1,r−1<min⁡{al,ar}sum_{l+1,r-1}<\min\{a_l,a_r\}suml+1,r−1​<min{al​,ar​} 就说明 xxx 一定无法突破 [l,r][l,r][l,r] 的限制，也就是无解。并且如果 xxx 不被任何一个这样的 [l,r][l,r][l,r] 包含就一定有解。

直接枚举每个 [l,r][l,r][l,r] 显然无法接受，但有个结论是总共最多 O(nlog⁡V)O(n\log V)O(nlogV) 个这样的区间。证明就考虑假设存在两个区间 [l,r1][l,r_1][l,r1​] 和 [l,r2][l,r_2][l,r2​] 满足性质，那么 suml+1,r2>2⋅suml+1,r2−1>2⋅suml+1,r1sum_{l+1,r_2}>2\cdot sum_{l+1,r_2-1}>2\cdot sum_{l+1,r_1}suml+1,r2​​>2⋅suml+1,r2​−1​>2⋅suml+1,r1​​，所以对于每个 lll 只存在 O(log⁡V)O(\log V)O(logV) 个符合条件的 rrr，总个数也就是 O(nlog⁡V)O(n\log V)O(nlogV)。同样可以证明包含任意一点的线段数也是 O(log⁡V)O(\log V)O(logV) 的，这里就不证了。

快速找到这些线段可以使用线段树二分。询问时相当于问有多少个点没有被线段覆盖，同样用线段树维护即可。

对于修改 (x,y)(x,y)(x,y) 就暴力删去与 xxx 有关的线段，修改后再加入。

然后考虑询问为任意区间的情况。

不妨设询问为 [L,R][L,R][L,R]，那么对于全局的一个线段 [l,r][l,r][l,r] 满足 L≤l≤r≤RL\leq l\leq r\leq RL≤l≤r≤R 或者 l≤L≤r≤Rl\leq L\leq r\leq Rl≤L≤r≤R 或 L≤l≤R≤rL\leq l\leq R\leq rL≤l≤R≤r 的话这个线段一定能造成贡献，而如果 [l,r][l,r][l,r] 完全包含 [L,R][L,R][L,R] 就说明 [l,r][l,r][l,r] 不能造成贡献，找到这些线段再去掉即可。

时间复杂度：O((n+q)log⁡nlog⁡V)O\left((n+q)\log n\log V\right)O((n+q)lognlogV)。
