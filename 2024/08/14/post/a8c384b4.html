P3309 [SDOI2014] 向量集 题解

Description

维护一个向量集合，在线支持以下操作：

  • A x y（∣x∣,∣y∣≤108|x|,|y| \le 10^8∣x∣,∣y∣≤108）：加入向量 (x,y)(x,y)(x,y)；
  • Q x y l r（∣x∣,∣y∣≤108|x|,|y| \le 10^8∣x∣,∣y∣≤108，1≤l≤r≤t1 \le l \le r \le t1≤l≤r≤t，其中 ttt 为已经加入的向量个数）：询问第 lll 个到第 rrr 个加入的向量与向量 (x,y)(x,y)(x,y) 的点积的最大值。

集合初始时为空，操作次数 ≤4×105\leq 4\times 10^5≤4×105。

Solution

不妨设查询时最优的向量为 (a,b)(a,b)(a,b)，那么 (a,b)⋅(x,y)=ax+by=y(xy⋅a+b)(a,b)\cdot (x,y)=ax+by=y\left(\frac{x}{y}\cdot a+b\right)(a,b)⋅(x,y)=ax+by=y(yx​⋅a+b)。

括号里面的东西是一个关于 (a,b)(a,b)(a,b) 的一次函数，所以可以先求出这个区间的凸包然后在凸包上二分（注意这里 bbb 可能是负数，所以需要同时维护上凸壳和下凸壳）。

考虑怎么求出凸包。

容易发现可以维护一个线段树，对于线段树上每个节点维护这个节点对应区间目前加入的点的凸包。

由于每个点只会被加入到 O(log⁡n)O(\log n)O(logn) 个节点，所以可以直接平衡树维护每个节点的凸包，时间复杂度是 O(nlog⁡2n)O(n\log^2n)O(nlog2n)，常数较大且过于复杂，考虑更好的做法。

上面做法的问题在于每次需要对于凸包实现动态插入，而维护凸包更好的做法是静态建凸包。

注意到每次查询访问到的节点一定被插满了，即这些节点一定不会再被修改。

所以对于每次修改，只需要找到所有已经被插满的节点然后对于这些节点静态建凸包即可。

这样常数就小很多了。

时间复杂度：O(nlog⁡2n)O(n\log^2n)O(nlog2n)。
