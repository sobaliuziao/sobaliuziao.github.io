CF506E Mr. Kitayuta&#39;s Gift 题解

Description

给定一个长度为 nnn 的小写字符串 sss 和一个正整数 mmm。

要求在 sss 中插入恰好 mmm 个小写字符使其回文的方案数，两个方案不同当且仅当它们得到的串不同，与插入顺序和位置无关。

n≤200,m≤109n \le 200,m \le 10^9n≤200,m≤109，答案对 104+710^4 + 7104+7 取模。

Solution

先考虑 n+mn+mn+m 为偶数的情况。

设 fi,l,rf_{i,l,r}fi,l,r​ 表示最终的字符串的前 iii 与后 iii 位与 sss 尽量匹配，最终剩下 sl,…,rs_{l,\dots,r}sl,…,r​ 没有匹配的方案数，gig_igi​ 表示前 iii 位与后 iii 位已经能与 sss 完全匹配的方案数。

容易发现答案是 g(n+m)/2g_{(n+m)/2}g(n+m)/2​。考虑转移。

如果 sl=srs_l=s_rsl​=sr​ 且 r−l≤1r-l\leq 1r−l≤1，则 gi+1←fi,l,r,fi+1,l,r←25⋅fi,l,rg_{i+1}\leftarrow f_{i,l,r},f_{i+1,l,r}\leftarrow 25\cdot f_{i,l,r}gi+1​←fi,l,r​,fi+1,l,r​←25⋅fi,l,r​。

如果 sl=srs_l=s_rsl​=sr​ 且 r−l>1r-l>1r−l>1，则 fi+1,l+1,r−1←fi,l,r,fi+1,l,r←25⋅fi,l,rf_{i+1,l+1,r-1}\leftarrow f_{i,l,r},f_{i+1,l,r}\leftarrow 25\cdot f_{i,l,r}fi+1,l+1,r−1​←fi,l,r​,fi+1,l,r​←25⋅fi,l,r​。

如果 sl≠srs_l\neq s_rsl​=sr​，则 fi+1,l+1,r←fi,l,r,fi+1,l,r−1←fi,l,r,fi+1,l,r←24⋅fi,l,rf_{i+1,l+1,r}\leftarrow f_{i,l,r},f_{i+1,l,r-1}\leftarrow f_{i,l,r},f_{i+1,l,r}\leftarrow 24\cdot f_{i,l,r}fi+1,l+1,r​←fi,l,r​,fi+1,l,r−1​←fi,l,r​,fi+1,l,r​←24⋅fi,l,r​。

并且 gi+1←26⋅gig_{i+1}\leftarrow 26\cdot g_igi+1​←26⋅gi​。

可以发现这个东西的转移图是个自动机。一个点 sl,rs_{l,r}sl,r​ 如果满足 sl=srs_l=s_rsl​=sr​ 则有 252525 个自环，否则有 242424 个自环，起点为 sl,rs_{l,r}sl,r​，终点有 262626 个自环。不妨设 242424 个自环的为红点，252525 个的为绿点，可以发现图长这样：

考虑优化。

注意到对于图中的一个从起点到终点的不包含自环的链，2cnt25+cnt24=n或n+12cnt_{25}+cnt_{24}=n或n+12cnt25​+cnt24​=n或n+1，所以 cnt25=⌈n−cnt242⌉cnt_{25}=\left\lceil\frac{n-cnt_{24}}{2}\right\rceilcnt25​=⌈2n−cnt24​​⌉，那么图中只有 O(n)O(n)O(n) 种不同的链，如下图：

所以可以对于每种链，求出这种链的出现次数再乘上这个链的方案数即可。

可以做到 O(n4log⁡(n+m))O\left(n^4\log (n+m)\right)O(n4log(n+m))。

但是还是过不了。

注意到上面那个做法有很多浪费，因为这 nnn 条链有很多结构是类似的，可以把他们压到一张图上：

那么先跑一遍矩乘就可以 O(1)O(1)O(1) 求出任意两点间的方案数，于是做到 O(n3log⁡(n+m))O\left(n^3\log (n+m)\right)O(n3log(n+m)) 了。

还有 n+mn+mn+m 为奇数的情况。

这里先求出长度为 n+m+1n+m+1n+m+1 的答案，可以发现多算的部分就是最后一步从形如 sl,l+1s_{l,l+1}sl,l+1​ 的绿点走到终点的方案数，所以可以跑出 n+m−1n+m-1n+m−1 的矩阵，再枚举这样的 sl,l+1s_{l,l+1}sl,l+1​ 和对应的起点减去答案即可。

时间复杂度：O(n3log⁡(n+m))O\left(n^3\log (n+m)\right)O(n3log(n+m))。
