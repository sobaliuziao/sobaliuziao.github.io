CF626G Raffles 题解

Description

  • 有 nnn 个奖池，第 iii 个奖池的奖金是 pip_ipi​，已经有 lil_ili​ 张彩票押在上面。
  • 现在你有 ttt 张彩票，你需要将你的彩票分配到这些奖池中，并且保证你在每个奖池中押的彩票数不能超过该奖池原有的彩票数。
  • 若你在第 iii 个奖池中押了 tit_iti​ 张彩票，则你中奖的概率为 titi+li\frac{t_i}{t_i + l_i}ti​+li​ti​​，若你中奖，你可以获得这个奖池的全部奖金 pip_ipi​。
  • 一共有 qqq 次事件，每次事件会使某个 lil_ili​ 加 111 或减 111。
  • 你需要在每个事件后求出在最佳方案下你获得的奖金总数的最大期望值。
  • n,t,q≤2×105n,t,q \le 2 \times 10^5n,t,q≤2×105，pi,li≤103p_i,l_i \le 10^3pi​,li​≤103，答案精度误差 ≤10−6\le 10^{-6}≤10−6。

Solution

首先单次 O(tlog⁡n)O(t\log n)O(tlogn) 是很容易的，就先假设所有 ti=0t_i=0ti​=0，每次取出让 ti→ti+1t_i\to t_i+1ti​→ti​+1 的增量的最大值，由于对于每个 iii，tit_iti​ 越大增量越小，所以每次贪心取最大值是对的。

考虑怎么支持修改。

不妨设修改了 xxx，让 lx←lx+1l_x\leftarrow l_x+1lx​←lx​+1。

有一个结论是每次选出当前已经选择的 Δ\DeltaΔ 里的最小值和没选的 Δ\DeltaΔ 的最大值，如果这个最小值小于最大值就贪心地替换，替换的次数不超过 111 次。

证明就考虑设 ΔE(k)=pxlx(lx+k)(lx+k+1),ΔE′(k)=px(lx+1)(lx+k+1)(lx+k+2)\Delta E(k)=\dfrac{p_xl_x}{(l_x+k)(l_x+k+1)},\Delta E'(k)=\dfrac{p_x(l_x+1)}{(l_x+k+1)(l_x+k+2)}ΔE(k)=(lx​+k)(lx​+k+1)px​lx​​,ΔE′(k)=(lx​+k+1)(lx​+k+2)px​(lx​+1)​。

注意到 ΔE′(k)=px(lx+1)(lx+k+1)(lx+k+2)>ΔE(k+1)=pxlx(lx+k+1)(lx+k+2)\Delta E'(k)=\dfrac{p_x(l_x+1)}{(l_x+k+1)(l_x+k+2)}>\Delta E(k+1)=\dfrac{p_xl_x}{(l_x+k+1)(l_x+k+2)}ΔE′(k)=(lx​+k+1)(lx​+k+2)px​(lx​+1)​>ΔE(k+1)=(lx​+k+1)(lx​+k+2)px​lx​​，所以 xxx 只有可能是选了的最小的增量被替换，所以最多只有一次。

对于 lx←lx−1l_x\leftarrow l_x-1lx​←lx​−1 的情况同理可证结论仍成立。

时间复杂度：O((n+q+t)log⁡n)O((n+q+t)\log n)O((n+q+t)logn)。
