CF585F Digits of Number Pi 题解

Description

给定长度为 nnn 的数字串 sss 和长度为 ddd 的不含前导零的数字串 x,y(x≤y)x,y(x \le y)x,y(x≤y)。

求存在长度至少为 ⌊d2⌋\left\lfloor\frac{d}{2}\right\rfloor⌊2d​⌋ 的子串是 sss 的子串的数字串 t∈[x,y]t \in [x,y]t∈[x,y] 的数量。

n≤103n \le 10^3n≤103，d≤50d \le 50d≤50，答案对 109+710^9+7109+7 取模。

Solution

先把 sss 所有长度为 ⌊d2⌋\left\lfloor\frac{d}{2}\right\rfloor⌊2d​⌋ 的子串拿出来，那么相当于要求这些子串必须在 ttt 里出现，考虑用总数减去没出现的数量。

考虑用 [0,y][0,y][0,y] 的答案减去 [0,x−1][0,x-1][0,x−1] 的答案，这样就只有上界了。

注意到这里是很多个字符串匹配一个串，考虑把 sss 的这些子串加到 AC 自动机里，那么这些子串没在 ttt 里出现当且仅当从前往后扫 ttt 的每一个字符，每次让 cur←triecur,ticur\leftarrow trie_{cur,t_i}cur←triecur,ti​​，如果这里的 curcurcur 每次都不在 sss 子串对应的节点上就说明子串没在 ttt 里出现。

这样就可以 dp 了。设 fi,j,0/1f_{i,j,0/1}fi,j,0/1​ 表示 1∼i−11\sim i-11∼i−1 走到 jjj，i∼ni\sim ni∼n 每次不走子串对应节点，后面有没有卡上界的限制的方案数。

转移就每次枚举 tit_iti​ 即可。
