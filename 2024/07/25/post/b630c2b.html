CF559E Gerald and Path 题解

Description

  • 有 nnn 条线段。
  • 每条线段给定其中一端的位置及长度。
  • 求所有线段覆盖的最大长度。
  • n≤100n \le 100n≤100。

Solution

考虑 dp。

先按照一端的位置进行排序，设 fi,j,0/1f_{i,j,0/1}fi,j,0/1​ 表示前 iii 个线段，右端点最靠右的线段是 jjj 向左/右覆盖，所有线段的最大长度。

直接枚举 i+1i+1i+1 转移可能会出现 i+1i+1i+1 完全覆盖了 jjj 而无法算贡献，但是思考一下会发现如果 i+1i+1i+1 完全覆盖 jjj 则把 jjj 删掉也毫无影响，所以只用钦定 jjj 没有被完全覆盖，然后枚举下一个对答案有影响的线段。

设 d0d_0d0​ 为 kkk 倒的方向，转移即为：fk,k,d0←fi,j,d+min⁡{posk+d0lenk−(posj+d⋅lenj),lenk}f_{k,k,d_0}\leftarrow f_{i,j,d}+\min\{pos_k+d_0 len_k-(pos_j+d\cdot len_j), len_k\}fk,k,d0​​←fi,j,d​+min{posk​+d0​lenk​−(posj​+d⋅lenj​),lenk​}。

但是可能会出现这种情况：

红的是枚举的下一个线段 kkk，但是可能 kkk 向左并且存在一个 xxx 使得 i<x<ki<x<ki<x<k 且 posx+lenx>poskpos_x+len_x>pos_kposx​+lenx​>posk​，此时 xxx 也会有贡献，贡献显然为 posx+lenx−poskpos_x+len_x-pos_kposx​+lenx​−posk​。

容易发现 xxx 对答案的贡献只与其右端点有关，并且这些线段一定是向右倒，所以枚举下一个没有完全覆盖的线段 kkk 时还需要维护位于 (i,k)(i,k)(i,k) 这个区间里往右倒的线段的右端点最大值。

转移即为 fk,x,1←fi,j,d+min⁡{posk+d0lenk−(posj+d⋅lenj),lenk}+(posx+lenx−(posk+d0lenk))f_{k,x,1}\leftarrow f_{i,j,d}+\min\{pos_k+d_0 len_k-(pos_j+d\cdot len_j), len_k\}+(pos_x+len_x-(pos_k+d_0 len_k))fk,x,1​←fi,j,d​+min{posk​+d0​lenk​−(posj​+d⋅lenj​),lenk​}+(posx​+lenx​−(posk​+d0​lenk​))。
