Description

Solution

显然如果 k>(n2)k>\binom{n}{2}k>(2n​) 就一定无解。

构造时会发现肯定要尽量弄成相同的然后进行微调，那么设 mmm 为最大的数满足 (m2)≤k\binom{m}{2}\leq k(2m​)≤k，r=k−(m2)r=k-\binom{m}{2}r=k−(2m​)。

这个时候直接选 mmm 个 222 会发现多出来的 rrr 很难微调，因为这个时候要是调整加数的话最小就是增加 mmm 了。

这时可以把 mmm 个数拆成 rrr 个 AAA 和 m−rm-rm−r 个 BBB，然后找 111 个 CCC 使得 A+B,2A,2B,A+CA+B,2A,2B,A+CA+B,2A,2B,A+C 均为完全平方数并且其他的都不是完全平方数，剩下多的 n−m−1n-m-1n−m−1 个 DDD 只要随便找一个数使得加出来不是完全平方数即可。
