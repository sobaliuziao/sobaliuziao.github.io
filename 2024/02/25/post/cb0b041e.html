[ARC155D] Avoid Coprime Game 题解

Description

非负整数 x,yx,yx,y 的最大公约数记为 gcd⁡(x,y)\gcd(x,y)gcd(x,y)，规定 gcd⁡(x,0)=gcd⁡(0,x)=x\gcd(x,0)=\gcd(0,x)=xgcd(x,0)=gcd(0,x)=x。

黑板上写了 NNN 个整数 A1,A2,...,ANA_1,A_2,...,A_NA1​,A2​,...,AN​，这 NNN 个数的最大公约数是 111。Takahashi 和 Aoki 在玩游戏，有一个变量 GGG 初值为 000，他们轮流进行以下操作：

从黑板上选择一个数 aaa，必须满足 gcd⁡(a,G)≠1\gcd(a,G)\ne 1gcd(a,G)=1，从黑板上擦掉这个数，并将 GGG 的值改为 gcd⁡(a,G)\gcd(a,G)gcd(a,G)。

Takahashi 先手，谁无法操作就输了，两人都采取最优策略。

请你对于 i=1,2,..,Ni=1,2,..,Ni=1,2,..,N 分别判断，假如第一步 Takahashi 选择的数是 AiA_iAi​，最后谁会获胜。

  • $ 2\ \leq\ N\ \leq\ 2\ \times\ 10^5 $
  • $ 2\ \leq\ A_i\ \leq\ 2\ \times\ 10^5 $

Code

考虑对于必胜必败态进行 dp，不妨设当前 gcd 为 GGG，注意到删数很难用状态表示，但是发现删掉的数一定是当前 GGG 的倍数，而其他 GGG 的倍数与 GGG 的 gcd 还是 GGG，并且不是 GGG 的倍数的数一定没被删。

所以只要记录 GGG 和当前轮数即可刻画这个状态，显然过不了。

先考虑每次 GGG 一定会变小的情况，设 fif_ifi​ 表示 G=iG=iG=i 是否必胜/必败，cnticnt_icnti​ 表示 iii 的倍数的个数。

那么枚举一个 jjj 使得 ∃x,gcd(i,x)=j\exists x,gcd(i,x)=j∃x,gcd(i,x)=j，如果 fjf_jfj​ 为必败，则 fif_ifi​ 必胜。如果所有 jjj 全必胜，则 fif_ifi​ 必败。

但是这题 GGG 不一定会变小，考虑什么情况下 GGG 不会变小。

注意到如果存在一个 fj(j<i)f_j(j<i)fj​(j<i) 满足其是必败态，则当前操作一定最优。所以 GGG 不变小当且仅当所有转移到的 fjf_jfj​ 都必胜，则两人一定不停操作直到必须变小，即操作到 cnticnt_icnti​ 轮的人会必胜。

所以只要记录一维状态表示当前操作了奇数/偶数轮，fi,0/1f_{i,0/1}fi,0/1​ 表示当前 G=iG=iG=i，在这之前操作了偶数/奇数轮。

然后同样进行 dp，如果后继状态全必胜，则 fi,1−(cnti mod 2)f_{i,1-(cnt_i\bmod 2)}fi,1−(cnti​mod2)​ 必胜。
