P9353 [JOI 2023 Final] Modern Machine 题解

Description

Bitaro 生日这天收到了一个 JOI 机作为生日礼物。JOI 机由一个球，NNN 条光带和 MMM 个按钮组成。光带从 111 到 NNN 编号。当 Bitaro 打开开关时，光带 i (1≤i≤N)i\ (1\le i\le N)i (1≤i≤N) 会发出颜色 CiC_iCi​ 的光（蓝光 (B)(\texttt{B})(B) 或红光 (R)\texttt{R})R)）。按钮从 111 到 MMM 编号。如果 Bitaro 按下按钮 j (1≤j≤M)j\ (1\le j\le M)j (1≤j≤M)，将发生如下事情。

  1. 把球放置在光带 AjA_jAj​ 上。
  2. 光带 AjA_jAj​ 变成红色（不管它原来是什么颜色）
  3. 进行如下操作，直到球被移除。
    令 ppp 为球目前所在的光带编号。
    • 如果光带 ppp 是蓝色，
      光带 ppp 变为红色。在此之后，如果 p=1p=1p=1，这个球就被移除。否则，球移向光带 p−1p-1p−1。
    • 如果光带 ppp 是红色，
      光带 ppp 变为蓝色。在此之后，如果 p=Np=Np=N，这个球就被移除。否则，球移向光带 p+1p+1p+1。

Bitaro 对 JOI 机十分感兴趣。他计划进行 QQQ 次实验。在第 k (1≤k≤Q)k\ (1\le k\le Q)k (1≤k≤Q) 次实验中，在 Bitaro 开启电源后，他将按 Lk,Lk+1,…RkL_k,L_k+1,\ldots R_kLk​,Lk​+1,…Rk​ 的顺序按下这些开关。在 Bitaro 按下一个开关后，他将等到球被移除后再按下下一个开关。

给定 JOI 机和实验的情况，写一个程序计算对于每个实验，当实验结束后红色的光带有多少。

注：每次实验之间互相独立。

Solution

先考虑怎么暴力地求出答案。

结论是对于一个在第 iii 个位置的操作，一定是把前 iii 个蓝球染红或者后 n−i+1n-i+1n−i+1 个红球染蓝。证明就考虑最终状态只和最后一次将前缀染红或后缀染蓝的位置有关。

假设最后一次是将前缀染红。在 [1,i−1][1,i-1][1,i−1] 这些位置中碰到红色会变向，[i,n][i,n][i,n] 碰到蓝色会变向，设 [1,i−1][1,i-1][1,i−1] 中有 kkk 个红色，i−1−ki-1-ki−1−k 个蓝色，那么左边变 kkk 次向，右边则有 k+1k+1k+1 次，所以右边会把 k+1k+1k+1 个蓝色染红，左边 i−1−ki-1-ki−1−k 个，加起来就是将前 iii 个蓝色染红。对于后缀染蓝是同理的。

由于这两种操作不能同时发生，所以只需要通过红/蓝球的个数即可判断选择哪个。

然后考虑第子任务 4,5 怎么做。

设当前前 ttt 个是红，操作位置为 iii，由于 iii 初始的颜色会有影响所以需要分类讨论：

如果 i≤ti\leq ti≤t 且 i≤n−ti\leq n-ti≤n−t，则 t←t+it\leftarrow t+it←t+i，否则 t←t−(n−i+1)t\leftarrow t-(n-i+1)t←t−(n−i+1)。

如果 i>ti>ti>t 且 i≤n−t−1i\leq n-t-1i≤n−t−1，则 t←t+i+1t\leftarrow t+i+1t←t+i+1，否则 t←t−(n−i)t\leftarrow t-(n-i)t←t−(n−i)。

写成简洁的形式：

fi(t)={(t+i) mod (n+1)            (i≤t)(t+i+1) mod (n+1)            (i>t)f_i(t)= \begin{cases} (t+i)\bmod (n+1)\ \ \ \ \ \ \ \ \ \ \ \ &(i\leq t)\\ (t+i+1)\bmod (n+1)\ \ \ \ \ \ \ \ \ \ \ \ &(i> t) \end{cases}fi​(t)={(t+i)mod(n+1)            (t+i+1)mod(n+1)            ​(i≤t)(i>t)​

注意到这是个分段函数并且段数是 O(操作序列大小)O(操作序列大小)O(操作序列大小) 的，所以线段树暴力维护分段函数即可，时间复杂度：O(Mlog⁡2N+Qlog⁡N)O\left(M\log^2N+Q\log N\right)O(Mlog2N+QlogN)

对于一般情况，操作任意时刻一定是子任务 4,5 或者一段前缀红，后缀蓝，中间不变的形态。

为了简化写法，先在所有蓝之前或者末尾分个段和所有红之后或者开头分个段，这样每次将前 iii 个蓝变红就只需要让红的前缀段的指针往后挪 iii 个，红变蓝同理。

假设当前红色的前缀长度为 rrr，蓝色的后缀长度为 bbb，考虑找到第一个前后缀汇合的时刻。

那么在这个时刻之前，假设操作位置 i≤ri\leq ri≤r，如果前 iii 个蓝染红，则 r←r+ir\leftarrow r+ir←r+i，否则就汇合了。如果 i≥n−b+1i\geq n-b+1i≥n−b+1，后 n−i+1n-i+1n−i+1 个红染蓝则 b←b+n−ib\leftarrow b+n-ib←b+n−i，否则也汇合了。

如果 r+1≤i≤n−br+1\leq i\leq n-br+1≤i≤n−b 就不好做了，但是注意到这样的 iii 是很少的，因为每次操作至少会让 r/br/br/b 中的一个翻倍，所以只有 O(log⁡N)O(\log N)O(logN) 个。

但是要快速找到在中间的操作仍然是不好做的，因为前后缀的长度是一直在变化的。这时可以设不超过 rrr 的最大 222 的幂次为 xxx，不超过 bbb 的最大幂次为 yyy，对于 x+1≤i≤n−yx+1\leq i\leq n-yx+1≤i≤n−y 的操作仍然会让 x,yx,yx,y 中的至少一个翻倍，这样的操作仍然只有 O(log⁡N)O(\log N)O(logN) 个。

于是就可以预处理了，设 nxtx,y,knxt_{x,y,k}nxtx,y,k​ 表示在 rrr 为 xxx，bbb 为 yyy 的情况下，aka_kak​ 后面的第一个在 [x+1,n−y][x+1,n-y][x+1,n−y] 内的操作下标，sumrx,y,ksumr_{x,y,k}sumrx,y,k​ 和 sumbx,y,ksumb_{x,y,k}sumbx,y,k​ 表示在 rrr 为 xxx，bbb 为 yyy 的情况下前 kkk 个操作对 r/br/br/b 的贡献。

询问时如果在 nxtnxtnxt 之前都无法汇合则跳到 nxt，更新 rrr 和 bbb 并算上 nxtnxtnxt 的贡献，否则二分出第一个汇合的时刻即可。

时间复杂度：O((M+Q)log⁡2N)O\left((M+Q)\log^2 N\right)O((M+Q)log2N)。
