P8868 [NOIP2022] 比赛 题解

Description

小 N 和小 O 会在 2022 年 11 月参加一场盛大的程序设计大赛 NOIP！小 P 会作为裁判主持竞赛。小 N 和小 O 各自率领了一支 nnn 个人的队伍，选手在每支队伍内都是从 111 到 nnn 编号。每一个选手都有相应的程序设计水平。具体的，小 N 率领的队伍中，编号为 iii（1≤i≤n1 \leq i \leq n1≤i≤n）的选手的程序设计水平为 aia _ iai​；小 O 率领的队伍中，编号为 iii（1≤i≤n1 \leq i \leq n1≤i≤n）的选手的程序设计水平为 bib _ ibi​。特别地，{ai}\{a _ i\}{ai​} 和 {bi}\{b _ i\}{bi​} 还分别构成了从 111 到 nnn 的排列。

每场比赛前，考虑到路途距离，选手连续参加比赛等因素，小 P 会选择两个参数 l,rl, rl,r（1≤l≤r≤n1 \leq l \leq r \leq n1≤l≤r≤n），表示这一场比赛会邀请两队中编号属于 [l,r][l, r][l,r] 的所有选手来到现场准备比赛。在比赛现场，小 N 和小 O 会以掷骰子的方式挑选出参数 p,qp, qp,q（l≤p≤q≤rl \leq p \leq q \leq rl≤p≤q≤r），只有编号属于 [p,q][p, q][p,q] 的选手才能参赛。为了给观众以最精彩的比赛，两队都会派出编号在 [p,q][p, q][p,q] 内的、程序设计水平值最大的选手参加比赛。假定小 N 派出的选手水平为 mam _ ama​，小 O 派出的选手水平为 mbm _ bmb​，则比赛的精彩程度为 ma×mbm _ a \times m _ bma​×mb​。

NOIP 总共有 QQQ 场比赛，每场比赛的参数 l,rl, rl,r 都已经确定，但是 p,qp, qp,q 还没有抽取。小 P 想知道，对于每一场比赛，在其所有可能的 p,qp, qp,q（l≤p≤q≤rl \leq p \leq q \leq rl≤p≤q≤r）参数下的比赛的精彩程度之和。由于答案可能非常之大，你只需要对每一场答案输出结果对 2642 ^ {64}264 取模的结果即可。

Solution

考虑把询问离线下来然后对 rrr 做扫描线。

设 xi=max⁡j=iraj,yi=max⁡j=irbjx_i=\max\limits_{j=i}^{r}{a_j},y_i=\max\limits_{j=i}^{r}{b_j}xi​=j=imaxr​aj​,yi​=j=imaxr​bj​。

那么区间 [l0,r0][l_0,r_0][l0​,r0​] 的答案就是 rrr 取 [l0,r0][l_0,r_0][l0​,r0​] 时 xl0×yl0x_{l_0}\times y_{l_0}xl0​​×yl0​​ 的历史版本和 SSS。

首先可以用单调栈维护对于每个 rrr，他能控制 xxx 的范围和控制 yyy 的范围，所以当 rrr 往右移一格，只会有三种操作：

  1. 将区间的 xxx 更改为 ara_rar​。
  2. 将区间的 yyy 更改为 ara_rar​。
  3. 对于 [1,r][1,r][1,r] 里的所有 iii，让 SiS_iSi​ 加 xi×yix_i\times y_ixi​×yi​。

最后需要多次查询区间 SSS 之和。

考虑用线段树维护，容易发现每次操作之后 SSS 的增量一定可以表示为：addx×X+addy×Y+addxy×XY+addcadd_{x}\times X+add_y\times Y+add_{xy}\times XY+add_caddx​×X+addy​×Y+addxy​×XY+addc​，其中 addx,addy,addxy,addcadd_x,add_y,add_{xy},add_caddx​,addy​,addxy​,addc​ 都是常数。

所以可以维护懒标记 tag=(setx,sety,addx,addy,addxy,addc)tag=(set_x,set_y,add_x,add_y,add_{xy},add_c)tag=(setx​,sety​,addx​,addy​,addxy​,addc​) 分别表示区间 xxx 赋值标记，区间 yyy 赋值标记和四个系数。

考虑怎样合并两个懒标记 tag1,tag2tag_1,tag_2tag1​,tag2​。

这里需要分类讨论 tag1tag_1tag1​ 是否有 xxx 赋值和 yyy 赋值。

  1. 如果 xxx 和 yyy 都有赋值，那么只用更新 addcadd_caddc​。

  2. 如果 xxx 有，yyy 没有，那么可以用 tag2tag_2tag2​ 的 addxyadd_{xy}addxy​ 和 addyadd_yaddy​ 更新 addtadd_taddt​，addxadd_xaddx​ 更新 addcadd_caddc​（xxx 没有 yyy 没有是同理的）。

  3. 如果 xxx 和 yyy 都没有，那么只要将 tag2tag_2tag2​ 的 addxadd_xaddx​ 更新 addxadd_xaddx​，addyadd_yaddy​ 更新 addyadd_yaddy​，addxyadd_{xy}addxy​ 更新 addxyadd_xyaddx​y 即可。

不要忘记 addcadd_caddc​ 要直接合并。
