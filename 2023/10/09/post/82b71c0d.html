正睿 NOIP2023 20连 Day1 T2 题解

Description

有一面由 n×mn\times mn×m 个格子组成的墙，每个格子要么是黑色，要么是白色。你每次将会进行这样的操作：等概率随机选择一个位置 (x,y)(x,y)(x,y)，和一个颜色 ccc（黑色或者白色），（1≤x≤n,1≤y≤m1 \leq x \leq n, 1 \leq y \leq m1≤x≤n,1≤y≤m, 任意 (x,y,c)(x,y,c)(x,y,c) 的组合选择它的概率均为 12×n×m\frac {1} {2\times n\times m}2×n×m1​），然后将在 (x,y)(x,y)(x,y) 左上角的所有格子的颜色涂成 ccc。

即将所有满足 1≤x′≤x,1≤y′≤y1 \leq x' \leq x, 1 \leq y' \leq y1≤x′≤x,1≤y′≤y 的 (x′,y′)(x',y')(x′,y′) 格子上的颜色涂成 ccc。

这次操作的代价为涂的格子的数量，即 x×yx\times yx×y。给定初始状态和终止状态，问期望要花费多少代价才能将墙面从初始状态涂成终止状态。

n,m≤5n,m\leq 5n,m≤5，对 998244353998244353998244353 取模。

Solution

首先有个显然的想法就是对所有的状态直接状压然后高斯消元解方程。

但是这样做时间复杂度是 O(23nm)O(2^{3nm})O(23nm)，过不了。

考虑优化这个状压方式，即找到一种等价类，使得同一等价类会转移到同一个等价类。

注意到如果一个点右下方有一个初始状态与结束状态不同，那么这个点当前的状态就没用了，因为右上方的一定会覆盖它。

设 pi,jp_{i,j}pi,j​ 表示 (i,j)(i,j)(i,j) 右下方是否全部满足当前状态 === 结束状态。

容易发现 ppp 值为 111 的一定是一个在右下角的阶梯，那么状态数总共就只有 Cn+mnC_{n+m}^{n}Cn+mn​ 了。

然后考虑转移，假设是操作 (x,y,c)(x,y,c)(x,y,c)，那么不在操作区域内的 ppp 值一定不变。

对于一个 (i,j)(i,j)(i,j) 满足 1≤i≤x,1≤j≤y1\leq i\leq x,1\leq j\leq y1≤i≤x,1≤j≤y，pi,jp_{i,j}pi,j​ 操作后为 111 当且仅当 (i,j)−(x,y)(i,j)-(x,y)(i,j)−(x,y) 这个矩形的最终状态全为 ccc 并且 px+1,jp_{x+1,j}px+1,j​ 和 pi,y+1p_{i,y+1}pi,y+1​ 都为 111。

容易发现这样做是对的。

然后对这个状态做高斯消元即可。

时间复杂度：O((Cn+mn)3)O\left((C_{n+m}^{n}) ^3\right)O((Cn+mn​)3)。
