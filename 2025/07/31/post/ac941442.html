CF2089C2 Key of Like (Hard Version)

Description

有 nnn 名成员参与游戏，他们按顺序轮流尝试解锁 lll 把锁。

每名成员在每轮中会根据历史信息选择最佳的钥匙和锁组合，选择的目标是最大化成功匹配的概率。成员们每次尝试时，只会使用尚未被尝试过的钥匙和锁。

这里除了能匹配锁的真实钥匙外，还有一些仿制钥匙（总数为 kkk），它们不能打开任何锁。

1≤n≤100,1≤l≤5000,0≤k≤251 \leq n \leq 100, 1 \leq l \leq 5000, 0 \leq k \leq 251≤n≤100,1≤l≤5000,0≤k≤25。

Solution

首先如果 k=0k=0k=0，询问策略一定是对于任意一个锁，按顺序询问目前没有配对的所有钥匙，直到能配对。

如果存在仿制钥匙，可以虚拟出 kkk 个锁，依次对应每个仿制钥匙。

设目前有 xxx 个锁（不算虚拟的），yyy 个仿制钥匙，第一次询问的是 aaa 号锁，和 bbb 号钥匙。

那么如果下一次询问的 aaa 不变，改变询问的钥匙，概率则为 1x+y−1\frac{1}{x+y-1}x+y−11​。

如果下一次询问的 bbb 不变，改变询问的锁，由于与 aaa 配对的钥匙一定在去掉 bbb 的所有钥匙中，所以 bbb 是真钥匙的概率是 x−1x+y−1\frac{x-1}{x+y-1}x+y−1x−1​，再随机一个锁和 bbb 配对的概率是 1x−1\frac{1}{x-1}x−11​，所以下次询问正确的概率是 x−1x+y−1⋅1x−1=1x+y−1\frac{x-1}{x+y-1}\cdot\frac{1}{x-1}=\frac{1}{x+y-1}x+y−1x−1​⋅x−11​=x+y−11​。

两个都改变显然不优，所以策略是以 x−12x+y−2\frac{x-1}{2x+y-2}2x+y−2x−1​ 的概率固定 bbb，依次询问所有的锁；以 x+y−12x+y−2\frac{x+y-1}{2x+y-2}2x+y−2x+y−1​ 的概率固定 aaa，依次询问所有的钥匙。

现在就可以 dp 了。设 fi,j,kf_{i,j,k}fi,j,k​ 表示目前剩余 iii 个锁，jjj 个仿制钥匙，做到了第 kkk 个人的概率。

设 prp_rpr​ 表示 mod n=r\bmod n=rmodn=r 的所有轮数的概率。

对于第一种情况，询问到第 ppp 个锁才找到配对的概率是 1x+y\frac{1}{x+y}x+y1​，由于这个固定所以可以 O(n)O(n)O(n) 计算 prp_rpr​，找不到的情况概率是 yx+y\frac{y}{x+y}x+yy​。

第二种情况是同理的。

但是直接转移是 O(n2lk)O(n^2lk)O(n2lk)，注意到 prp_rpr​ 只有 O(1)O(1)O(1) 个极长连续段，所以可以前缀和优化。

时间复杂度：O(nlk)O(nlk)O(nlk)。
