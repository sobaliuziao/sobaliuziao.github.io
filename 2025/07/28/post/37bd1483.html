CF2097F Lost Luggage 题解

Description

众所周知，航空公司"Trouble"经常丢失行李，为此关心的记者们决定计算可能无法归还给旅客的行李最大数量。

航空公司"Trouble"在编号从 111 到 nnn 的 nnn 个机场间运营航班。记者们的实验将持续 mmm 天。已知在实验第一天午夜前，第 jjj 个机场有 sjs_jsj​ 件遗失行李。在第 iii 天会发生以下事件：

  • 早晨，同时起飞 2n2n2n 个航班，包括 nnn 个第一类航班和 nnn 个第二类航班：
    • 第一类第 jjj 个航班从机场 jjj 飞往机场 (((j−2) mod n)+1)(((j-2) \bmod n )+ 1)(((j−2)modn)+1)（前一个机场，第一个机场的前一个是最后一个），最多可运输 ai,ja_{i,j}ai,j​ 件遗失行李；
    • 第二类第 jjj 个航班从机场 jjj 飞往机场 ((j mod n)+1)((j \bmod n) + 1)((jmodn)+1)（后一个机场，最后一个机场的后一个是第一个），最多可运输 ci,jc_{i,j}ci,j​ 件遗失行李；
  • 下午，机场会进行遗失行李检查。如果当天航班起飞后，第 jjj 个机场剩余 xxx 件行李且 x≥bi,jx \ge b_{i, j}x≥bi,j​，则至少会有 x−bi,jx - b_{i, j}x−bi,j​ 件行李被找到，不再视为遗失；
  • 晚上，当天所有 2n2n2n 个航班结束，运输的遗失行李抵达对应机场。

对于每个 kkk 从 111 到 mmm，记者们想知道在前 kkk 天的检查中可能未被找到的遗失行李最大数量。注意每个 kkk 的计算都是独立的。

1≤n≤12,1≤m≤20001\leq n\leq 12,1\leq m\leq 20001≤n≤12,1≤m≤2000。

Solution

首先这个显然是网络流，有一个比较显然的最大流建模是建给第 i(0≤i≤m)i(0\leq i\leq m)i(0≤i≤m) 天建一个点 (i,j)(i,j)(i,j) 表示这一天晚上机场 jjj 的行李数量，同时第 iii 天有个汇点 TiT_iTi​。连边就是 (i−1,j)(i-1,j)(i−1,j) 向 (i,j)(i,j)(i,j) 连流量为 bi,jb_{i,j}bi,j​ 的边，(i−1,j)(i-1,j)(i−1,j) 向 (i,j−1)(i,j-1)(i,j−1) 连流量为 ai,ja_{i,j}ai,j​ 的边，(i−1,j)(i-1,j)(i−1,j) 向 (i,j+1)(i,j+1)(i,j+1) 连流量为 ci,jc_{i,j}ci,j​ 的边，(i,j)(i,j)(i,j) 向 TiT_iTi​ 连流量为 +∞+\infty+∞ 的边。第 iii 天的答案就是 S→TiS\to T_iS→Ti​ 的最大流。

但是直接跑肯定是不行的。考虑转最小割。

由于 n≤12n\leq 12n≤12 且只有相邻层数之间的边，所以可以直接按照天数把和 SSS 连通的点压入状态。

设 fi,Sf_{i,S}fi,S​ 表示前 iii 天，钦定第 iii 层和源点相连的点为集合 SSS 内的点，其余的全和汇点相连。

转移为：

fi,S=min⁡T{fi−1,S+∑j∈T∑k∉Sei−1,j,k}f_{i,S}=\min_{T}{\left\{f_{i-1,S}+\sum_{j\in T}\sum_{k\notin S}{e_{i-1,j,k}}\right\}}fi,S​=Tmin​⎩⎪⎨⎪⎧​fi−1,S​+j∈T∑​k∈/S∑​ei−1,j,k​⎭⎪⎬⎪⎫​

注意：这里转移的边必须满足前面的点属于 TTT，后面的不属于 SSS，不能加入前面属于 SSS 后面不属于 TTT 的贡献，因为这样的边根本不会被经过！！！

直接转移是 O(m⋅4n)O(m\cdot 4^n)O(m⋅4n)，过不了。优化就考虑先把初始状态设为上一层的状态，然后从前往后逐位修改状态，设 gi,S,0/1g_{i,S,0/1}gi,S,0/1​ 表示修改了前 iii 位，目前状态为 SSS，且第 iii 位在修改前是 0/10/10/1 的最小答案。容易转移。

单次转移是 O(2nn)O(2^nn)O(2nn)。
