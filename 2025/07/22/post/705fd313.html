CF2122G Tree Parking 题解

Description

你得到一棵以 1 为根的树，共有 nnn 个结点。

对于每个 1≤i≤n1 \leq i \leq n1≤i≤n，有一辆车会在时间 lil_ili​ 从根结点进入。这辆车会沿着从根到结点 iii 的唯一路径（简单路径）瞬间行驶，并停在结点 iii。它将在时间 rir_iri​ 沿原路返回离开。

在车辆停在某个结点期间，该结点将被占用，不能被其他车辆通过。

当所有车辆都能在它们想要的时间进入并离开时，我们称这棵树是合法的（valid）。

请你计算有多少对序列 lll、rrr 满足以下条件：

  • 对于每个 iii，都有 li<ril_i < r_ili​<ri​；
  • 将 lll 和 rrr 拼接后得到的长度为 2n2n2n 的序列是 1,2,...,2n1, 2, ..., 2n1,2,...,2n 的一个排列；
  • 树是合法的（即所有车辆在各自的时间段可以顺利通过）。

现在的目标是：

对于所有有 nnn 个结点、恰好有 kkk 个叶子结点的有标号树（labeled trees）（注意：根结点 1 不算作叶子），求上述合法方案数的总和。

由于答案可能很大，请输出其对 998244353998244353998244353 取模后的结果。

1≤k<n≤2×1051\leq k<n\leq 2\times 10^51≤k<n≤2×105。

Solution

首先考虑如果已知树的形态之后怎么求答案。

显然是按照子树从下往上考虑，假设已经知道了 uuu 子树内除去 uuu 的 lll、rrr 分配方案了，由于 [lu,ru][l_u,r_u][lu​,ru​] 不能包含任意一个子树内点的左右端点，则 lu,rul_u,r_ulu​,ru​ 只有 2⋅szu−12\cdot sz_u-12⋅szu​−1 种方案，总方案数为 (2n)!⋅∏12szu=(2n)!2n⋅∏1szu\displaystyle(2n)!\cdot\prod\frac{1}{2sz_u}=\frac{(2n)!}{2^n}\cdot\prod\frac{1}{sz_u}(2n)!⋅∏2szu​1​=2n(2n)!​⋅∏szu​1​。

现在只需要求出所有有标号有根树的 ∏1szu\displaystyle\prod\frac{1}{sz_u}∏szu​1​ 即可，将这个乘上 n!n!n! 就是一个有根树的拓扑序数量。

考虑先固定拓扑序，再计算可以以当前序列为拓扑序的方案数。

即设 f(n,k)f(n,k)f(n,k) 表示已经确定了拓扑序 nnn 个数的连边方案，有 kkk 个叶子的方案数，则转移为：f(n,k)=f(n−1,k−1)⋅(n−k)+f(n−1,k)⋅kf(n,k)=f(n-1,k-1)\cdot(n-k)+f(n-1,k)\cdot kf(n,k)=f(n−1,k−1)⋅(n−k)+f(n−1,k)⋅k。最终答案为 f(n,k)⋅(n−1)!f(n,k)\cdot(n-1)!f(n,k)⋅(n−1)!，因为拓扑序第一项必须为 111，其余的可以随便排列。

现在考虑怎么快速求 f(n,k)f(n,k)f(n,k)。
