Description

  • 对于所有 iii 从 111 到 nnn，有 li≤ai≤ril_i \leq a_i \leq r_ili​≤ai​≤ri​；
  • a1⊕a2⊕…⊕an=xa_1 \oplus a_2 \oplus \ldots \oplus a_n = xa1​⊕a2​⊕…⊕an​=x，其中 ⊕\oplus⊕ 表示按位异或运算符。

1≤n≤2×105,1≤m≤181\leq n\leq 2\times 10^5,1\leq m\leq 181≤n≤2×105,1≤m≤18。

Solution

显然是 fwt。考虑求出 [li,ri][l_i,r_i][li​,ri​] 对应的 fwt 数组。设 pc(x)=popcount(x)\text{pc}(x)=\text{popcount}(x)pc(x)=popcount(x)。

先把 [li,ri][l_i,r_i][li​,ri​] 变成 [0,ri]−[0,li−1][0,r_i]-[0,l_i-1][0,ri​]−[0,li​−1]，现在问题变为求出 ∑i=0n(−1)pc(x&i)\sum_{i=0}^{n}{(-1)^{\text{pc}(x\&i)}}∑i=0n​(−1)pc(x&i)。

现在把 xxx 的 lowbit 拿出来，假设为 2b2^b2b，那么对于所有 iii 在 bbb 位之前没有顶到 nnn 的上界的所有数，由于 bbb 位的存在，一定会互相抵消。

然后再分讨一下可以发现答案为 (−1)pc(n&x)[n mod 2b+1−(n&2b)](-1)^{\text{pc}(n\&x)}\left[n\bmod 2^b+1-(n\&2^b)\right](−1)pc(n&x)[nmod2b+1−(n&2b)]，设 vb,n=n mod 2b+1−(n&2b)v_{b,n}=n\bmod 2^b+1-(n\&2^b)vb,n​=nmod2b+1−(n&2b)。

那么 fwtx=∏i=1n[(−1)pc(ri&x)vb,ri−(−1)pc((li−1)&x)vb,li−1]\displaystyle fwt_x=\prod_{i=1}^{n}{\left[(-1)^{\text{pc}(r_i\&x)}v_{b,r_i}-(-1)^{\text{pc}((l_i-1)\&x)}v_{b,l_i-1}\right]}fwtx​=i=1∏n​[(−1)pc(ri​&x)vb,ri​​−(−1)pc((li​−1)&x)vb,li​−1​]。

容易想到枚举 bbb，每次求上面的那个东西，再化简一下：

fwtx=∏i=1n[(−1)pc(ri&x)vb,ri−(−1)pc((li−1)&x)vb,li−1]=∏i=1n[(−1)pc((li−1)&x)vb,li−1⋅(−1+vb,rivb,li−1⋅(−1)pc(ri&x)+pc((li−1)&x))]=∏i=1n[(−1)pc((li−1)&x)vb,li−1⋅(−1+vb,rivb,li−1⋅(−1)pc((ri⊕(li−1))&x))]\begin{aligned} fwt_x=&\prod_{i=1}^{n}{\left[(-1)^{\text{pc}(r_i\&x)}v_{b,r_i}-(-1)^{\text{pc}((l_i-1)\&x)}v_{b,l_i-1}\right]}\\ =&\prod_{i=1}^{n}{\left[(-1)^{\text{pc}((l_i-1)\&x)}v_{b,l_i-1}\cdot\left(-1+\frac{v_{b,r_i}}{v_{b,l_i-1}}\cdot(-1)^{pc(r_i\&x)+pc((l_i-1)\&x)}\right)\right]}\\ =&\prod_{i=1}^{n}{\left[(-1)^{\text{pc}((l_i-1)\&x)}v_{b,l_i-1}\cdot\left(-1+\frac{v_{b,r_i}}{v_{b,l_i-1}}\cdot(-1)^{pc((r_i\oplus(l_i-1))\&x)}\right)\right]}\\ \end{aligned}fwtx​===​i=1∏n​[(−1)pc(ri​&x)vb,ri​​−(−1)pc((li​−1)&x)vb,li​−1​]i=1∏n​[(−1)pc((li​−1)&x)vb,li​−1​⋅(−1+vb,li​−1​vb,ri​​​⋅(−1)pc(ri​&x)+pc((li​−1)&x))]i=1∏n​[(−1)pc((li​−1)&x)vb,li​−1​⋅(−1+vb,li​−1​vb,ri​​​⋅(−1)pc((ri​⊕(li​−1))&x))]​

那个小括号外面的部分可以直接用类似 fwt 的东西做。小括号里面的东西是形如 ∏(ai+bixci)\displaystyle\prod(a_i+b_ix^{c_i})∏(ai​+bi​xci​) 的东西，也是个经典技巧，设 fwtx,0/1fwt_{x,0/1}fwtx,0/1​ 表示目前 ∏(ai+bixci)\displaystyle\prod\left(a_i+b_ix^{c_i}\right)∏(ai​+bi​xci​) 的乘积和 ∏(ai−bixci)\displaystyle\prod\left(a_i-b_ix^{c_i}\right)∏(ai​−bi​xci​)，具体转移看代码。
