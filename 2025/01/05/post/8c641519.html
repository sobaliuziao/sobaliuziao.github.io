LOJ #3273. 「JOISC 2020 Day1」扫除 题解

Description

平面直角坐标系上一个等腰直角三角形，维护 444 种操作：

  1. 加入 (x,y)(x,y)(x,y)。
  2. 把 y≤ly\leq ly≤l 的点横坐标变成 max⁡⁡(x,n−l)\max⁡(x,n-l)max⁡(x,n−l)。
  3. 把 x≤lx\leq lx≤l 的点纵坐标变成 max⁡(y,n−l)\max(y,n-l)max(y,n−l)。
  4. 查询第 iii 个点现在的位置。

1≤n≤109,1≤m≤5×105,1≤Q≤1061\leq n\leq 10^9,1\leq m\leq 5\times 10^5,1\leq Q\leq 10^61≤n≤109,1≤m≤5×105,1≤Q≤106。

Solution

考虑没有一操作怎么做。

容易发现对于任意时刻都存在一条左上到右下的轮廓线，满足所有点要么在轮廓线上，要么位置没有发生改变。

所以先求出每个点第一次被移动的时刻 pip_ipi​，同时维护一个平衡树表示轮廓线上的点，在 pip_ipi​ 时刻将 iii 号点加入平衡树，修改时直接将需要修改的区间 split 出来打标记即可。

如果有一操作，会让某个点在加入的时候在轮廓线下面，导致上面的做法不正确。考虑规避掉一操作。

假设要求出某个点 ppp 经过 [l,r][l,r][l,r] 操作后的结果，那么在线段树上找到 [l,r][l,r][l,r] 对应的 O(log⁡n)O(\log n)O(logn) 个区间，并将这个点依次插入这些区间。

求答案时进行类似线段树分治的做法，每次将当前线段树节点 [l,r][l,r][l,r] 上的点一起做 [l,r][l,r][l,r] 操作，然后将这些点操作完的坐标挂到对应的线段树上的下一个区间即可。

时间复杂度：O((m+Q)log⁡(m+Q))O((m+Q)\log (m+Q))O((m+Q)log(m+Q))。
