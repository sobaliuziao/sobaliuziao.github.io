[AT WTF2022 Day2 D] Cat Jumps 题解

Description

给定一个正整数序列 A1,A2,⋯ ,ANA_1, A_2, \cdots, A_NA1​,A2​,⋯,AN​。定义 S=N+∑1≤i≤NAiS = N + \sum_{1 \leq i \leq N} A_iS=N+∑1≤i≤N​Ai​。

猫 Snuke 拥有 SSS 张卡片。每张卡片上写有一个整数，分别为 A1,A2,⋯ ,AN,−1,⋯ ,−1A_1, A_2, \cdots, A_N, -1, \cdots, -1A1​,A2​,⋯,AN​,−1,⋯,−1。特别地，写有 −1-1−1 的卡片共有 ∑1≤i≤NAi\sum_{1 \leq i \leq N} A_i∑1≤i≤N​Ai​ 张。

Snuke 现在位于数轴上坐标为 000 的位置。接下来，它将进行 SSS 次如下操作：

  • 设 Snuke 当前所在位置的坐标为 xxx。从持有的卡片中选择一张并丢弃。设丢弃的卡片上的数为 vvv，则跳跃到坐标为 x+vx + vx+v 的位置。如果跳跃后的坐标为 000，则获得 111 枚硬币。

对于每个 k=1,2,⋯ ,Nk = 1, 2, \cdots, Nk=1,2,⋯,N，求 Snuke 恰好获得 kkk 枚硬币的跳跃序列有多少种，结果对 998244353998244353998244353 取模。

注意计数的是跳跃序列。也就是说，如果两张卡片上的数相同，则丢弃它们的操作被视为相同的。

1≤N≤50001 \leq N \leq 50001≤N≤5000，1≤Ai≤50001 \leq A_i \leq 50001≤Ai​≤5000。

Solution

先把所有 aia_iai​ 相同的卡片看成不同的，最后除以每个出现次数的阶乘即可。

考虑求出钦定 kkk 个硬币的方案数，最后再二项式反演回去即可。

对于一个集合 SSS，设其大小为 ccc，总和为 sumsumsum，则它的内部出现一个硬币的方案数为 (sum+1)(sum+2)⋯(sum+c)(sum+1)(sum+2)\cdots(sum+c)(sum+1)(sum+2)⋯(sum+c)。

现在相当于是要求将整个集合划分为 kkk 个非空子集后，每个子集的权值乘积之和。

但是单个子集的权值很复杂，不好刻画。考虑组合意义。

建出一个有 n2n^2n2 条边的有向图，wi,j=aj+[j≤i]w_{i,j}=a_j+[j\leq i]wi,j​=aj​+[j≤i]。确定了一个集合划分后，每个点向任意与其在同一集合内的点连边，求连出来的边的权值乘积之和。

这是因为显然每个点之间互相独立，而一个集合内编号第 iii 小的点所能连的边的边权之和为 sum+isum+isum+i，所以这个边权乘积之和就是答案！

由于每个点出度为一，所以连出来的图是个内向基环树森林，求出每个连通块数对应的方案数再乘上第二类斯特林数就是上面问题的答案。

考虑容斥环数。

对于没有钦定在环上的点，显然是随便连，贡献为 ∑j=1naj+i\sum_{j=1}^{n}a_j+i∑j=1n​aj​+i。

对于环上的点，由于环的问题不好做，所以考虑将其断为链。

具体的，将 wi,jw_{i,j}wi,j​ 的形式变为 aj+1−[i<j]a_j+1-[i<j]aj​+1−[i<j]，现在问题变为每条边可以在 aj+1a_j+1aj​+1 和 −[i<j]-[i<j]−[i<j] 里任选一个乘起来，问乘积之和。

由于要对答案有贡献，一个环不可能都选 −[i<j]-[i<j]−[i<j]，所以所有选 aj+1a_j+1aj​+1 的边就能把环断成链，显然每条链的编号大小一定递增，且一个链的链头权值为 ai+1a_i+1ai​+1，后面的全是 −1-1−1。

把这些链找出来，再随意组合成环后权值是不变的，这部分的贡献是第一类斯特林数。

考虑 dp。

设 fi,jf_{i,j}fi,j​ 表示考虑了编号为 1∼i1\sim i1∼i 的点，目前有 jjj 条链的贡献之和，转移为：fi,j←fi−1,j⋅(−j)+fi−1,j−1⋅(ai+1)+fi−1,j⋅(S+i)f_{i,j}\leftarrow f_{i-1,j}\cdot(-j)+f_{i-1,j-1}\cdot(a_i+1)+f_{i-1,j}\cdot(S+i)fi,j​←fi−1,j​⋅(−j)+fi−1,j−1​⋅(ai​+1)+fi−1,j​⋅(S+i)。

这三种转移分别代表 iii 是接在原来的链的末尾，还是新开一条链，还是直接不钦定在环上。

做完 dp 后在反推回去即可。

时间复杂度：O(n2)O(n^2)O(n2)。
