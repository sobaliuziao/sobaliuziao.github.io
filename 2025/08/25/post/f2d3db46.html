[ABC311Ex] Many Illumination Plans 题解

Description

给定一棵根节点为 111 的有根树 TTT，树中共有 NNN 个节点，编号从 111 到 NNN。对于每个顶点 iii（2≤i≤N2 \leq i \leq N2≤i≤N），其父节点是 PiP_iPi​。每个节点都有两个非负整数属性，分别称为美丽值和重量。节点 iii 的美丽值为 BiB_iBi​，重量为 WiW_iWi​。此外，节点被涂上红色或蓝色，其颜色用整数 CiC_iCi​ 表示：当 Ci=0C_i=0Ci​=0 时，节点 iii 为红色；当 Ci=1C_i=1Ci​=1 时，为蓝色。

对于每一个节点 vvv，定义函数 F(v)F(v)F(v) 表示以下问题的解：

从树 TTT 中提取出以 vvv 为根的子树，称之为 UUU。对 UUU 可以进行若干次以下操作（操作不会改变未删除节点的属性）：

  • 选择一个非根节点 ccc，设 ccc 的父节点为 ppp。
  • 对于所有与 ccc 相连的边：
    • 假设边的另一端是 uuu，删除这条边，然后用一条以 ppp 为父节点的新边连接 ppp 和 uuu。
  • 删除节点 ccc 和边 p,cp,cp,c。

最终的 UUU 满足以下条件即为好的有根树：

  • UUU 中相连节点的颜色不同。
  • 所有节点的重量总和不超过 XXX。

找出在所有可能的好的有根树中，节点美丽值总和的最大值。

请输出每个节点 vvv 对应的 F(v)F(v)F(v)，即 F(1),F(2),…,F(N)F(1), F(2), \dots, F(N)F(1),F(2),…,F(N)。

2≤N≤200,0≤X≤500002\leq N\leq 200,0\leq X\leq 500002≤N≤200,0≤X≤50000。

Solution

首先这题有个很简单的想法是设 fu,s,0/1f_{u,s,0/1}fu,s,0/1​ 表示 uuu 的子树，选的总重量为 sss，最上面的那些点的颜色为 0/10/10/1 的最大美丽度之和，暴力转移就是 O(nX2)O(nX^2)O(nX2)。

注意到如果按照上面的做法从下往上转移，则无法规避掉单次 O(X2)O(X^2)O(X2) 的 min⁡\minmin 加卷积，所以考虑从上往下 dp，将 dp 数组合并改为往 dp 中插入元素。

先考虑固定子树的根怎么做。

对于当前的点 uuu，由于儿子之间是平等的，所以有个很巧妙的想法是往 dfs 的状态里加入一个数组 fff，表示这个子树里面的选择需要在 fff 的基础上更新，然后 dfs 的返回结果改成两个大小为 x+1x+1x+1 的数组，分别表示 uuu 的子树内选的最浅的点颜色为 0/10/10/1，且在 fff 的基础上更新的结果数组。

由于 uuu 的儿子中有一个儿子可以只遍历一次，其余都需要两次，容易想到先遍历重儿子，得到只有重儿子子树的 f0f_0f0​ 和 f1f_1f1​。然后对于其它儿子 vvv，分别调用 f0←dfs(v,f0)[0],f1←dfs(v,f1)[1]f_0\leftarrow \text{dfs}(v,f_0)[0],f_1\leftarrow\text{dfs}(v,f_1)[1]f0​←dfs(v,f0​)[0],f1​←dfs(v,f1​)[1]。

这个东西的复杂度是 T(szu)=T(szsonu)+2∑v≠sonuT(szv)+O(X)≤3⋅T(szu/2)+O(X)=O(nlog⁡23X)=O(n1.59X)\displaystyle T(sz_u)=T(sz_{son_u})+2\sum_{v\neq son_u}{T(sz_v)}+O(X)\leq 3\cdot T(sz_u/2)+O(X)=O(n^{\log_23}X)=O(n^{1.59}X)T(szu​)=T(szsonu​​)+2v=sonu​∑​T(szv​)+O(X)≤3⋅T(szu​/2)+O(X)=O(nlog2​3X)=O(n1.59X)。

暴力对于每个子树做这件事情就是 O(n2.59X)O(n^{2.59}X)O(n2.59X)，过不了。

考虑优化。

可以感受到上面的做法还是有些浪费，因为如果要求以 uuu 为根的答案，这个需要用到 sonuson_usonu​ 从零开始的 dp 结果，暴力枚举根的化这个 sonuson_usonu​ 的 dp 结果就会算两次，很不优。

所以可以往 dfs 的状态中加一维 opopop 表示是否需要从零开始计算 uuu 子树里的答案，即 dfs(u,f,0/1)\text{dfs}(u,f,0/1)dfs(u,f,0/1)。

如果 op=0op=0op=0，则按照上面的做法转移即可。如果 op=1op=1op=1，则对于轻儿子全都从零开始计算，uuu 不继承这些结果。然后 uuu 先继承重儿子的结果，对于轻儿子和 op=0op=0op=0 的做法一样。

可以证明时间复杂度仍然是 O(n1.59X)O(n^{1.59}X)O(n1.59X)。

时间复杂度：O(n1.59X)O(n^{1.59}X)O(n1.59X)。
