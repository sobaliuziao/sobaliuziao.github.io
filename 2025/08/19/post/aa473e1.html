LOJ #2392. 「JOISC 2017 Day 1」烟花棒 题解

Description

有 NNN 人站在一条数轴上。他们人手一个烟花，每人手中的烟花都恰好能燃烧 TTT 秒。每个烟花只能被点燃一次。

111 号站在原点，iii 号 (1≤i≤N)(1\le i\le N)(1≤i≤N) 到 111 号的距离为 XiX_iXi​。保证 X1=0,X_1=0,X1​=0, X1,X2,…,XNX_1, X_2, \dots, X_NX1​,X2​,…,XN​ 单调递增（可能有人位置重叠）。

开始时， KKK 号的烟花刚开始燃烧,，其他人的烟花均未点燃。他们的点火工具坏了，只能用燃着的烟花将未点燃的烟花点燃。当两人位置重叠且其中一人手中的烟花燃着时，另一人手中的烟花就可以被点燃。忽略点火所需时间。

求至少需要以多快的速度跑，才能点燃所有人的烟花（此时可能有些人的烟花已经熄灭了）。速度必须是一个非负整数。

1≤K,N≤105,1≤T≤109,0≤Xi≤109(1≤i≤N),X1=0,{XN}1\le K, N \le 10^5, 1\le T\le 10^9, 0\le X_i\le 10^9 (1\le i\le N), X_1 = 0, \{X_N\}1≤K,N≤105,1≤T≤109,0≤Xi​≤109(1≤i≤N),X1​=0,{XN​} 单调递增。

Solution

显然是二分答案，考虑怎么 check。

首先没点燃的人一定是向 kkk 方向走。

有个关键结论是一个点燃的人碰到一个没点燃的人的时候是不会先点燃的，而是两个人一起走，等一个烟花即将熄灭时再续上。

证明就考虑设那个点燃的烟花剩余时间是 ttt，相遇位置是 xxx，如果瞬间点燃并同向走显然不优。如果反向走，则可以点燃 [x−2tv,x+2Tv][x-2tv,x+2Tv][x−2tv,x+2Tv] 内的烟花。两个人先一起往左走，可以点燃 [x−2tv,x][x-2tv,x][x−2tv,x] 内的烟花，此时续上并往右走，由于右边在前 ttt 的时间内是和两个人速度完全一致，所以它们相对位置不变，往右则能够点燃 [x,x+2Tv][x,x+2Tv][x,x+2Tv] 内的烟花，和瞬间点燃是一样的。

容易发现按照上面的策略，每次被点燃过的烟花一定是一段区间 [L,R][L,R][L,R]，且刚点到 [L,R][L,R][L,R] 的时候剩余总时间是 t(R−L)−xR−xL2vt(R-L)-\frac{x_R-x_L}{2v}t(R−L)−2vxR​−xL​​，只要每次区间往左右拓展时这个东西始终是非负的即可。

也就是 2tv(R−L)−(xR−xL)=(2tvR−xR)−(2tvL−xL)≥02tv(R-L)-(x_R-x_L)=(2tvR-x_R)-(2tvL-x_L)\geq 02tv(R−L)−(xR​−xL​)=(2tvR−xR​)−(2tvL−xL​)≥0，设 ai=2Tvi−xia_i=2Tvi-x_iai​=2Tvi−xi​，则需要满足 aL≤aRa_L\leq a_RaL​≤aR​。

现在问题变为有个初始区间 [k,k][k,k][k,k]，每次可以拓展左右端点，要求任意时刻都要满足 aL≤aRa_L\leq a_RaL​≤aR​，问能不能走到。这是这道题，可以直接套用做法。

不过还有个做法是令 f(L,R)=2tv(R−L)−(xR−xL)f(L,R)=2tv(R-L)-(x_R-x_L)f(L,R)=2tv(R−L)−(xR​−xL​)，每次往左右拓展贪心选更大的显然不对，但是会发现往一侧拓展时如果目前贡献为负数是不会停止的，否则一开始就往另一边走或者一直走直到这边贡献非负一定更优。

所以我们可以找到分别往左右拓展第一次能让贡献非负的位置，然后贪心地选择目前能拓展的贡献更大的一边拓展即可。

但是如果当前局面两边都只能为负数，就不太能做了。注意到最终状态是固定的，所以再时空倒流就能保证总有一边贡献非负了。
