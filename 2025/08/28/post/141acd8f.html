P10055 [CCO 2022] Good Game 题解

Description

Finn 正在玩一个叫做 Twos and Threes 的游戏。Twos and Threes 是一个单人游戏，它在一维棋盘上进行。在初始位置，有 NNN 个方块排成一行，每个方块标有 A\tt{A}A 或 B\tt{B}B。方块从左到右编号为 111 到 NNN。Finn 可以进行以下操作：

  • 选择 222 或 333 个连续的方块，它们有相同的标签，将它们从棋盘上移除并将剩余的方块连接起来，从左到右重新编号方块。

如果棋盘上的所有方块都被移除，Finn 就赢得了游戏。你的任务是帮助 Finn 确定一个赢得游戏的操作序列，或者确定游戏无法获胜。

1≤N≤1061 \leq N \leq 10^61≤N≤106。

Solution

容易发现每次选择 222 或 333 个删掉，等价于可以删掉任意长度 ≥2\geq 2≥2 的相同连续段，所以可以先把所有极长连续段缩起来，设长度为 a1,a2,…,ama_1,a_2,\ldots,a_ma1​,a2​,…,am​。

显然一次操作一定是把一整个连续段删掉，否则不优。假设我们把第 iii 个连续段删掉，整个序列会变成 a1,a2,…,ai−2,ai−1+ai+1,ai+2,…,ama_1,a_2,\ldots,a_{i-2},a_{i-1}+a_{i+1},a_{i+2},\ldots,a_ma1​,a2​,…,ai−2​,ai−1​+ai+1​,ai+2​,…,am​。由于我们只关心操作连续段的长度是否大于等于 222，所以把 aia_iai​ 变为 [ai≥2][a_i\geq 2][ai​≥2] 后，一次操作就变为：[...?1?...]→[...1...][...?1?...]\to [...1...][...?1?...]→[...1...]，因为两个段合并后长度一定大于等于 222。

先考虑 m=2k+1m=2k+1m=2k+1 的情况。

经过打表可以发现有解的充要条件是满足 ak+1=1a_{k+1}=1ak+1​=1 或者不存在一个长度为 kkk 的 000 连续段。

证明就考虑如果 ak+1=1a_{k+1}=1ak+1​=1 时，每次删掉正中间的段即可。否则如果存在一个长度为 kkk 的 000 连续段的话，设 preprepre 为 k+1k+1k+1 左边第一个 111，nxtnxtnxt 为 k+1k+1k+1 右边第一个 111。尽管 [1,pre][1,pre][1,pre] 和 [nxt,m][nxt,m][nxt,m] 全是 111，总共能消掉的 000 的数量也为 pre−1+m−nxt=m−1−(nxt−pre)≤k−1pre-1+m-nxt=m-1-(nxt-pre)\leq k-1pre−1+m−nxt=m−1−(nxt−pre)≤k−1，所以一定不可能。（注：减一是因为操作开头或者末尾的 111 没有意义）

如果不存在长度为 kkk 的 000 连续段，则我们一定可以通过一直删掉 nxtnxtnxt 位置的连续段来把 preprepre 移到正中间，然后一直操作 preprepre 即可。

如果 m=2km=2km=2k，则最后一次操作一定是对 111111 进行操作，由于在之前一定没有边界上的操作，所以两个 111 一定对应两个长度为奇数的区间，枚举一下是否存在这样的划分即可。

时间复杂度：O(n)O(n)O(n)。
