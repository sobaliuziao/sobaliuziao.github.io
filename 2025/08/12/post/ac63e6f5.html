CF1456E XOR-ranges 题解

Description

有 nnn 个位数不超过 KKK 的二进制变量 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​，其中 xix_ixi​ 的取值范围是 [li,ri][l_i, r_i][li​,ri​]。

给出数列 c0,c1,…,cK−1c_0, c_1, \dots, c_{K-1}c0​,c1​,…,cK−1​，并由此定义一个代价函数 f(x)f(x)f(x)：

f(x)=∑i=0K−1(⌊x2i⌋ mod 2)⋅cif(x) = \sum_{i=0}^{K-1} \left( \left\lfloor \frac{x}{2^i} \right\rfloor \bmod 2 \right) \cdot c_if(x)=i=0∑K−1​(⌊2ix​⌋mod2)⋅ci​

换句话说，f(x)f(x)f(x) 表示：如果 xxx 的二进制第 iii 位是 111，则代价加上 cic_ici​。

现在你需要确定每个变量的取值，使得：∑i=2nf(xi⊕xi−1)\sum_{i=2}^{n} f(x_i \oplus x_{i-1})∑i=2n​f(xi​⊕xi−1​) 最小；输出该最小值。

2≤n≤502 \leq n \leq 502≤n≤50，1≤K≤501 \leq K \leq 501≤K≤50，0≤li≤ri<2K0 \leq l_i \leq r_i < 2^K0≤li​≤ri​<2K，0≤ci≤10120 \leq c_i \leq 10^{12}0≤ci​≤1012。

Solution

首先显然是按照数位从高到低进行区间 dp，但是直接不太好刻画，因为如果区间有很多位置卡了上下界就会不好转移。

设当前位是 bbb，注意到如果到 bbb 位之后一个区间的数都没卡上下界了，那么把这个区间删掉就没有影响了。

考虑对上面这个东西进行 dp，即设 fb,l,r,x,yf_{b,l,r,x,y}fb,l,r,x,y​ 表示从最高位到第 bbb 位，[l+1,r−1][l+1,r-1][l+1,r−1] 都被删掉了，lll 卡了下界/上界，rrr 卡了下界/上界时 [l,r][l,r][l,r] 这个区间贡献的最小值。

转移时就枚举有哪些 [l+1,r−1][l+1,r-1][l+1,r−1] 的数在第 bbb 位被删掉，直接区间 dp 计算贡献就是 O(n3k)O(n^3k)O(n3k) 的，但是还有更好的写法。

就是考虑只枚举第一个在第 bbb 位被删掉，假设是 iii，那么 [l,i][l,i][l,i] 的贡献就是 fb+1,l,i,x,opf_{b+1,l,i,x,op}fb+1,l,i,x,op​，但是 [i,r][i,r][i,r] 的贡献不是 wb,i,r,x,y+fb,i,r,op,yw_{b,i,r,x,y}+f_{b,i,r,op,y}wb,i,r,x,y​+fb,i,r,op,y​，因为这里 iii 第 bbb 位需要取与 opopop 对应的界异或 111 的结果，转移就会存在问题。

容易发现可以加一维状态 zzz 表示 lll 这一位需不需要异或 111。这样就能直接转移了，即：fb,l,r,x,y,z←fb+1,l,i,x,op,0+wb,l,i,x,op,z⊕1+fb,i,r,op,y,1f_{b,l,r,x,y,z}\leftarrow f_{b+1,l,i,x,op,0}+w_{b,l,i,x,op,z\oplus 1}+f_{b,i,r,op,y,1}fb,l,r,x,y,z​←fb+1,l,i,x,op,0​+wb,l,i,x,op,z⊕1​+fb,i,r,op,y,1​，注意这里如果 opopop 对应 lil_ili​，则需要满足 lil_ili​ 第 bbb 位是 000，同理转移 rir_iri​ 就要这一位是 111。

不要忘记还有当前位没有新删掉点的转移：fb,l,r,x,y,z←fb+1,l,r,x,y,0+wb,l,r,x,y,zf_{b,l,r,x,y,z}\leftarrow f_{b+1,l,r,x,y,0}+w_{b,l,r,x,y,z}fb,l,r,x,y,z​←fb+1,l,r,x,y,0​+wb,l,r,x,y,z​。

时间复杂度：O(n3k)O(n^3k)O(n3k)。
