CF2062G Permutation Factory 题解

Description

给定两个长度为 nnn 的排列 p1,p2,…,pnp_1, p_2, \ldots, p_np1​,p2​,…,pn​ 和 q1,q2,…,qnq_1, q_2, \ldots, q_nq1​,q2​,…,qn​。每次操作中，你可以选择两个不同的整数 1≤i,j≤n1 \leq i, j \leq n1≤i,j≤n 并交换 pip_ipi​ 和 pjp_jpj​。该操作的成本为 min⁡(∣i−j∣,∣pi−pj∣)\min(|i - j|, |p_i - p_j|)min(∣i−j∣,∣pi​−pj​∣)。

请找到使 pi=qip_i = q_ipi​=qi​ 对所有 1≤i≤n1 \leq i \leq n1≤i≤n 成立的最小总成本，并输出达成该目标的交换操作序列。

一个长度为 nnn 的排列是由 111 到 nnn 的不同整数按任意顺序组成的数组。例如，[2,3,1,5,4][2, 3, 1, 5, 4][2,3,1,5,4] 是排列，但 [1,2,2][1, 2, 2][1,2,2] 不是排列（222 重复出现），[1,3,4][1, 3, 4][1,3,4] 也不是排列（当 n=3n=3n=3 时出现 444）。

n≤100n\leq 100n≤100。

Solution

首先每次操作的成本是两个东西的 min⁡\minmin，而最后又要最小化总成本，所以这两维可以拆开。

考虑把排列看成 nnn 个点，每个为 (i,pi)(i,p_i)(i,pi​)，每次有两种操作：

  1. 选择 i,ji,ji,j，用 ∣i−j∣|i-j|∣i−j∣ 的代价将 (i,pi)(i,p_i)(i,pi​) 移到 (j,pi)(j,p_i)(j,pi​)，(j,pj)(j,p_j)(j,pj​) 移到 (i,pj)(i,p_j)(i,pj​)。
  2. 选择 i,ji,ji,j，用 ∣pi−pj∣|p_i-p_j|∣pi​−pj​∣ 的代价将 (i,pi)(i,p_i)(i,pi​) 移到 (i,pj)(i,p_j)(i,pj​)，(j,pj)(j,p_j)(j,pj​) 移到 (j,pi)(j,p_i)(j,pi​)。

容易发现一次操作的代价就是移动的曼哈顿距离除以二，所以我们只关心移动的总曼哈顿距离。

由于最终所有 (j,qj)(j,q_j)(j,qj​) 上需要有点，所以一定是一一匹配的，不妨设最终是初始的 (i,pi)(i,p_i)(i,pi​) 移动到了 (mi,qmi)(m_i,q_{m_i})(mi​,qmi​​)，那么有一个显然的下界是 ∑i=1n(∣i−mi∣+∣pi−qmi∣)\sum_{i=1}^{n}{\left(|i-m_i|+|p_i-q_{m_i}|\right)}∑i=1n​(∣i−mi​∣+∣pi​−qmi​​∣)，可以证明这个下界是可以取到的。

先用费用流求出 mim_imi​。

构造就考虑两位实际上是独立的，而每一维等价于是有一个大小为 nnn 的排列 ppp，可以通过 ∣i−j∣|i-j|∣i−j∣ 的代价交换 pip_ipi​ 和 pjp_jpj​，要求最后 pi=pjp_i=p_jpi​=pj​。

这个是比较经典的问题，每次选择最小的 iii 使得 pi≠ip_i\neq ipi​=i，然后找到 pj=ip_j=ipj​=i 的这个 jjj，容易发现 pi,pi+1,…,pj−1p_i,p_{i+1},\ldots,p_{j-1}pi​,pi+1​,…,pj−1​ 一定存在一个数大于等于 jjj，找到这个位置交换即可，总共做至多 n(n−1)2\frac{n(n-1)}{2}2n(n−1)​ 次，因为每次会至少减少两个逆序对。

时间复杂度：O(n4)O(n^4)O(n4)。
