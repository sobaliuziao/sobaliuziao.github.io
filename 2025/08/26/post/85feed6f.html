QOJ #3082. Ascending Matrix 题解

Description

给定整数 N,M,K,R,C,VN, M, K, R, C, VN,M,K,R,C,V。求满足以下所有条件的 N×MN \times MN×M 整数矩阵 a=(ai,j)a = (a_{i,j})a=(ai,j​) 的数量，并对结果取模 998244353998244353998244353。

  • 对所有 1≤i≤N, 1≤j≤M1 \leq i \leq N,\, 1 \leq j \leq M1≤i≤N,1≤j≤M，有 1≤ai,j≤K1 \leq a_{i,j} \leq K1≤ai,j​≤K。
  • 对所有 1≤i≤N, 1≤j≤M−11 \leq i \leq N,\, 1 \leq j \leq M-11≤i≤N,1≤j≤M−1，有 ai,j≤ai,j+1a_{i,j} \leq a_{i,j+1}ai,j​≤ai,j+1​。
  • 对所有 1≤i≤N−1, 1≤j≤M1 \leq i \leq N-1,\, 1 \leq j \leq M1≤i≤N−1,1≤j≤M，有 ai,j≤ai+1,ja_{i,j} \leq a_{i+1,j}ai,j​≤ai+1,j​。
  • 并且满足 aR,C=Va_{R,C} = VaR,C​=V。

1≤N,M≤200,1≤K≤1001\leq N,M\leq 200,1\leq K\leq 1001≤N,M≤200,1≤K≤100。

Solution

（注：这里 RRR 和 CCC 默认都先减了 111）

首先这题不太好直接计数，考虑转格路后用 LGV 引理计数。

先找到数值 ≤i\leq i≤i 和 >i>i>i 的分界线 LiL_iLi​，这是个从 (0,m)(0,m)(0,m) 到 (n,0)(n,0)(n,0) 的方向只有左下的路径。

需要满足 LiL_iLi​ 完全在 Li+1L_{i+1}Li+1​ 的左上，但是可以有交点重合，那么将 LiL_iLi​ 向右下平移 i−1i-1i−1 步后就不会有交点了。

也就是说第 iii 个起点为 (i−1,m+i−1)(i-1,m+i-1)(i−1,m+i−1)，第 iii 个终点为 (n+i−1,i−1)(n+i-1,i-1)(n+i−1,i−1)，要求这 k−1k-1k−1 个路径不能有交。

然后去满足 ar,c=va_{r,c}=var,c​=v 的限制。

这时需要满足前 v−1v-1v−1 条路径需要经过 (r+v−2,c+v−2)(r+v-2,c+v-2)(r+v−2,c+v−2) 的左上角，且第 vvv 条路径需要经过 (r+v,c+v)(r+v,c+v)(r+v,c+v) 的右下角。

如果对前 v−1v-1v−1 和后 k−vk-vk−v 条路径按照不同的方式计数的化就不能用 LGV 引理进行容斥了，考虑统一标准。

容易发现它们都不能经过 (r+v−1,c+v−1)(r+v-1,c+v-1)(r+v−1,c+v−1)，那么可以把 (r+v−1,c+v−1)(r+v-1,c+v-1)(r+v−1,c+v−1) 删掉，问题变为满足不交限制之后要求经过 (r+v−2,c+v−2)(r+v-2,c+v-2)(r+v−2,c+v−2) 左上角的路径需要有恰好 v−1v-1v−1 条。

令 ai,ja_{i,j}ai,j​ 表示从第 iii 个起点走到第 jjj 个终点，且不经过 (r+v−2,c+v−2)(r+v-2,c+v-2)(r+v−2,c+v−2) 左上角的方案数；bi,jb_{i,j}bi,j​ 表示从第 iii 个起点走到第 jjj 个终点，且经过 (r+v−2,c+v−2)(r+v-2,c+v-2)(r+v−2,c+v−2) 左上角的方案数。然后跑 wi,j=ai,j+bi,jxw_{i,j}=a_{i,j}+b_{i,j}xwi,j​=ai,j​+bi,j​x 的行列式，要求出第 v−1v-1v−1 次系数。

插值维护即可。

时间复杂度：O(n3+k4)O(n^3+k^4)O(n3+k4)。
