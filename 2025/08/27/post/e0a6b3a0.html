LOJ #3409. 「2020-2021 集训队作业」Yet Another Linear Algebra Problem 题解

Description

您需要解决两个独立（但类似）的子问题：

问题一：给定 nnn 个在 GF(3)\mathrm{GF}(3)GF(3) 上的 mmm 维向量，记它们张成的线性空间为 VVV。求从 nnn 个向量中选出一组向量，使得它们是 VVV 的基的方案数。对 333 取模。

问题二：给定 nnn 个在 GF(2)\mathrm{GF}(2)GF(2) 上的 mmm 维向量，记它们张成的线性空间为 VVV。其中第 iii 个向量有颜色 cic_ici​。求从每种颜色中恰好选出一个向量，使得它们是 VVV 的基的方案数。对 222 取模。

注：为了凸显主要矛盾而忽略次要矛盾，保证 VVV 的维数为 mmm。

1≤n,m≤5001\leq n,m\leq 5001≤n,m≤500。

Solution

首先有个前置知识是 Binet Cauchy 公式：

对于 m×nm\times nm×n 的矩阵 AAA 和 n×mn\times mn×m 的矩阵 BBB（n≥mn\geq mn≥m），有：（AS,BSA_S,B_SAS​,BS​ 表示列/行下标在 SSS 中的子矩阵）

det⁡(AB)=∑∣S∣=mdet⁡(AS)det⁡(BS)\det(AB)=\sum_{|S|=m}{\det(A_S)\det(B_S)}det(AB)=∣S∣=m∑​det(AS​)det(BS​)

第一问就是问有多少个大小为 mmm 的子集，使得这个子集的秩非零。注意到在模 333 意义下，[x≠0]=x2[x\neq 0]=x^2[x=0]=x2，所以问题变为 ∑∣S∣=mdet⁡(AS)2=det⁡(ATA)\displaystyle\sum_{|S|=m}{\det(A_S)^2}=\det(A^TA)∣S∣=m∑​det(AS​)2=det(ATA)。

第二问等价于问 ∑∣S∣=mdet⁡(AS)[∪i∈S{ci}=U]\displaystyle\sum_{|S|=m}{\det(A_S)[\cup_{i\in S}{\{c_i\}}=U]}∣S∣=m∑​det(AS​)[∪i∈S​{ci​}=U]，其中 uuu 是颜色全集。考虑将第二个条件转为一个 n×mn\times mn×m 的矩阵的行列式。

容易发现这等价于让 Bi,j=[j=ci]B_{i,j}=[j=c_i]Bi,j​=[j=ci​]，如果 SSS 中有元素颜色相同，则 BSB_SBS​ 的秩一定是 000，否则是 111。于是答案为 det⁡(ATB)\det(A^TB)det(ATB)。

时间复杂度：O(n3)O(n^3)O(n3)。
