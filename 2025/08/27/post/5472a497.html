QOJ #3091. Japanese Knowledge 题解

Description

给定一个非递减的正整数序列 A=(A1,A2,…,AN)A = (A_1, A_2, \ldots, A_N)A=(A1​,A2​,…,AN​)

对于每个 k=0,1,2,…,Nk = 0, 1, 2, \ldots, Nk=0,1,2,…,N，要求计算满足以下条件的、长度为 NNN 的非递减非负整数序列 x=(x1,x2,…,xN)x = (x_1, x_2, \ldots, x_N)x=(x1​,x2​,…,xN​) 的数量，并对结果取模 998244353998244353998244353：

  1. 对所有 1≤i≤N1 \leq i \leq N1≤i≤N，有 xi≤Aix_i \leq A_ixi​≤Ai​。
  2. 恰好有 kkk 个下标 iii 满足 xi=Aix_i = A_ixi​=Ai​。

1≤N,Ai≤2.5×1051\leq N,A_i\leq 2.5\times 10^51≤N,Ai​≤2.5×105。

Solution

设 fk(a1,a2,…,an)f_k(a_1,a_2,\ldots,a_n)fk​(a1​,a2​,…,an​) 为有恰好 kkk 个 xi=aix_i=a_ixi​=ai​ 的方案数，g(a1,a2,…,an)g(a_1,a_2,\ldots,a_n)g(a1​,a2​,…,an​) 为不考虑 xi=aix_i=a_ixi​=ai​ 这条限制的总方案数。

首先这题只有第一个限制是能做的，但是加上第二个限制就不好做了。所以考虑怎么把第二个限制去掉。

有个想法是对第二个进行容斥，但是会发现是不行的。于是需要找一些关于 xi=aix_i=a_ixi​=ai​ 的性质。

这里先给出结论：所有 (ak+1−1,ak+2−1,…,an−1)(a_{k+1}-1,a_{k+2}-1,\ldots,a_n-1)(ak+1​−1,ak+2​−1,…,an​−1) 的方案都一一对应了一个原序列有 kkk 个 xi=aix_i=a_ixi​=ai​ 的方案。

证明就考虑如果有恰好 kkk 个 xi=aix_i=a_ixi​=ai​，把这 kkk 个数去掉后的 xi′x'_ixi′​ 一定要小于 ai+ka_{i+k}ai+k​。因为如果 xi′≥ai+kx'_i\geq a_{i+k}xi′​≥ai+k​，则 ai+k≤xi′≤xia_{i+k}\leq x'_i\leq x_iai+k​≤xi′​≤xi​，这时 xi,xi+1,…,xkx_i,x_{i+1},\ldots,x_kxi​,xi+1​,…,xk​ 都必须顶到上界，就矛盾了。

对于一个满足 xi′<ai+kx'_i<a_{i+k}xi′​<ai+k​ 的方案，考虑从小到大放到原数组中。每次一定是找到 xi′<ajx'_i<a_jxi′​<aj​ 的最小的 jjj 放进去，如果不是最小的 jjj，则最小的 kkk 一定会顶到上界，而 xi′<akx'_i<a_kxi′​<ak​，就矛盾了。由于已经满足了 xi′<ai+kx'_i<a_{i+k}xi′​<ai+k​，所以这么操作一定能找到唯一的一组方案。

现在问题变为对于每个后缀，求 g(ak−1,ak+1−1,…,an−1)g(a_k-1,a_{k+1}-1,\ldots,a_n-1)g(ak​−1,ak+1​−1,…,an​−1)。

考虑分治。

问题可以转化为有 nnn 个柱子，第 iii 个柱子高 hi=ai−1h_i=a_i-1hi​=ai​−1，问从最右侧每次往左或者往下走，有多少种走到 (i,0)(i,0)(i,0) 的方案。

我们定义函数 solve(l,r,F)solve(l,r,F)solve(l,r,F) 为当前分治区间为 [l,r][l,r][l,r]，且这个区间内的每个柱子的高度都减去 hl−1h_{l-1}hl−1​，从 nnn 走到当前的 (r,i)(r,i)(r,i) 的方案数为 FiF_iFi​；返回值为一个多项式 GGG，其中 GiG_iGi​ 为走到 l+il+il+i 的方案数。

每次找到中点 midmidmid，然后调用 solve(mid+1,r,F)solve(mid+1,r,F)solve(mid+1,r,F)，求出从最右边走到横着的黄线的每个位置的方案数，再通过 NTT 求出从横着的黄线走到竖黄线的每个位置的方案数 HHH，最后调用 solve(l,mid,H)solve(l,mid,H)solve(l,mid,H)。

在分治的过程中，还要更新 [mid+1,r][mid+1,r][mid+1,r] 终点在黄线下面的方案数，和上面的东西是类似的。
