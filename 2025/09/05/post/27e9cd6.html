CF1326F2 Wise Men (Hard Version) 题解

Description

有 nnn 位智者居住在一座美丽的城市中。他们中的一些人彼此认识。

对于智者的每一种 n!n!n! 种排列 p1,p2,…,pnp_1, p_2, \ldots, p_np1​,p2​,…,pn​，我们可以生成一个长度为 n−1n-1n−1 的二进制字符串：对于每个 1≤i<n1 \leq i < n1≤i<n，如果 pip_ipi​ 和 pi+1p_{i+1}pi+1​ 彼此认识，则设 si=1s_i=1si​=1，否则 si=0s_i=0si​=0。

对于所有可能的 2n−12^{n-1}2n−1 个二进制字符串，求有多少种排列会生成该二进制字符串。

n≤18n\leq 18n≤18。

Solution

由于排列不好做，考虑容斥在数列中出现过的数的集合 SSS，结束之后做一遍 FWT 即可。

这时会发现枚举 SSS 的复杂度已经有 O(2n)O(2^n)O(2n) 了，再用 dp 算答案的复杂度至少是 O(4nn)O(4^nn)O(4nn)，过不了。

考虑对相邻认识的人继续容斥。具体地，我们可以钦定若干个位置 iii，使得 sis_isi​ 必须是 111，那么整个排列就会被划分成若干个连续段，连续段内部必须满足相邻的人互相认识，连续段之间互不影响。

维护 gig_igi​ 表示在 SSS 的情况下长度为 iii 的不同连续段数量，直接搜索可以做到 O(4n)O(4^n)O(4n) 仍然过不了。

但是注意到我们只关心连续段中每个长度出现的次数，而不关心这些长度之间的顺序，所以不同的状态数实际上只有 nnn 拆分数 P(n)P(n)P(n) 个。

n=18n=18n=18 时 P(n)=385P(n)=385P(n)=385，直接搜出这些状态后再做即可。

时间复杂度：O(2nnP(n))O(2^nnP(n))O(2nnP(n))。
