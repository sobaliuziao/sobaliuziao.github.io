P13695 [CEOI 2025] theseus 题解

Description

当不在思考这些抽象哲学问题时，忒修斯会在闲暇时猎杀弥诺陶洛斯。但这一次，他必须先穿过一个黑暗而扭曲的迷宫。由于这并非易事，他请求阿里阿德涅为他引路。这个迷宫可以看作是一个连通的无向图，包含 nnn 个节点（编号 111 到 nnn）和 mmm 条边，并且有一个特殊节点 ttt，弥诺陶洛斯就在这里。

忒修斯完全看不到图的全貌，但阿里阿德涅可以。两人会先商定一个策略，使他能安全到达弥诺陶洛斯所在的节点：阿里阿德涅会在 mmm 条边的每一条上贴上 000 或 111 的标签。之后，忒修斯会从某个节点 sss 进入迷宫，而阿里阿德涅事先并不知道 sss 的位置。

由于迷宫极为黑暗，任何时刻他只能看到当前所在节点的编号、相邻节点的编号以及相邻边的标签。此外，由于迷宫结构扭曲，他永远无法记住自己之前到过的节点的任何信息。

为了安全到达弥诺陶洛斯，忒修斯必须在不超过 min⁡+C\min+Cmin+C 次移动内完成，其中 min⁡\minmin 是从 sss 到 ttt 的最短路径上的边数，CCC 是一个常数。

1≤n≤10000,1≤m≤50000,C=141 \leq n \leq 10000,1 \leq m \leq 50000,C = 141≤n≤10000,1≤m≤50000,C=14。

Solution

首先如果知道边的两端点 u,vu,vu,v 和边权 www 后，我们可以把它看成一条有向边，即如果 w=0w=0w=0，则方向为 min⁡(u,v)→max⁡(u,v)\min(u,v)\to\max(u,v)min(u,v)→max(u,v)，否则 max⁡(u,v)→min⁡(u,v)\max(u,v)\to\min(u,v)max(u,v)→min(u,v)。

那么我们求出 disidis_idisi​ 表示 i→ti\to ti→t 的最短路长度。然后对于每条无向边 u,vu,vu,v，如果 disu≠disvdis_u\neq dis_vdisu​=disv​，则让大的指向小的，否则让编号大的指向编号小的。

这是个答案正确的做法，但是最劣的步数是 min⁡\minmin 加上所有层点数减一的和，过不了。

由于层与层之间的边是必须要走的，所以这里要控制层内走的总边数在 log⁡n\log nlogn 范围内。

考虑利用启发式合并的思想，给每个点一个点权 aia_iai​，初始为 111，每次如果确定了一条边的方向 u→vu\to vu→v 后，就让 av←av+au,au←0a_v\leftarrow a_v+a_u,a_u\leftarrow 0av​←av​+au​,au​←0。

具体地，如果一条边 (u,v)(u,v)(u,v) 是层与层之间的边，则把其挂在层数较深的点上。否则挂在编号较大的点上。

然后从深往浅去枚举每一层，对于层内按照编号从大到小枚举每个点和挂在它上面的边，边的另一端也是从大到小枚举。

如果两端点层数不同，则层数深的指向浅的，并更新点权。如果层数相同，则点权小的指向点权大的，并更新点权。

走的时候每次走 uuu 的出边编号最大的点即可，这么做至多走 min⁡+log⁡n\min+\log nmin+logn 步。

证明就考虑每次走出去的出边一定是第一次让 uuu 的点权变为 000 的边，层内的排序保证了这一点。不妨设 bib_ibi​ 为 iii 达到过的最大点权，那么 uuu 对于走出去的点 vvv，如果是层与层之间的边，则 bv≥bub_v\geq b_ubv​≥bu​；如果是层内的边，则 bv≥2bub_v\geq 2b_ubv​≥2bu​，这样的边最多走 log⁡n\log nlogn 次。

总步数也就是 min⁡+log⁡n\min+\log nmin+logn。
