Pjudge #21728. 【CTS Round #1 Day 1】地雷 题解

Description

给定一棵 nnn 个顶点的树，其中第 iii（1≤i≤n−11 \le i \le n-11≤i≤n−1）条边连接了顶点 uiu_iui​ 与 viv_ivi​（1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n），其长度为 wiw_iwi​。

在每个顶点上均埋藏着一棵地雷。第 iii（1≤i≤n1 \le i \le n1≤i≤n）个顶点上的地雷的爆炸半径为 RiR_iRi​ ，伤害值为 hih_ihi​ 。

我们定义 dist(i,j)\mathrm{dist}(i, j)dist(i,j) 表示在树上顶点 iii 与顶点 jjj 的最短距离。即，dist(i,j)\mathrm{dist}(i, j)dist(i,j) 为顶点 iii 与 jjj 之间唯一的简单路径的边权之和。

当顶点 iii 处的地雷爆炸时，所有距离其不超过 RiR_iRi​ 的地雷都会一起爆炸。即，对于所有满足 dist(i,j)≤Ri\mathrm{dist}(i, j) \le R_idist(i,j)≤Ri​ 的地雷 jjj，如果其还没有爆炸，那么他也会被引爆。

对于每个 iii（i=1,2,⋯ ,ni = 1, 2, \cdots, ni=1,2,⋯,n），你希望求出，如果在起始时引爆了顶点 iii 处的地雷，则最终所有被引爆的地雷的伤害值之和。

1≤n≤1051 \le n \le 10^51≤n≤105，1≤hi≤1091\le h_i\le 10^91≤hi​≤109，0≤Ri≤10180 \le R_i \le 10^{18}0≤Ri​≤1018，1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n，1≤wi≤10121 \le w_i \le 10^{12}1≤wi​≤1012。

Solution

首先这题爆炸的过程会跳来跳去，没有一个固定的转移过程，考虑用点分治把跳的过程限定在点分树子树里。

先递归处理子树。设 frt,xf_{rt,x}frt,x​ 表示从 xxx 炸到 rtrtrt 的最大剩余长度（只考虑 rtrtrt 的子树），炸不到就设为 −∞-\infty−∞；grt,xg_{rt,x}grt,x​ 表示要想从 rtrtrt 炸到 xxx 的最小初始剩余长度。那么 xxx 能炸到 yyy 的条件是存在一个 rtrtrt，使得 frt,x≥grt,yf_{rt,x}\geq g_{rt,y}frt,x​≥grt,y​。

先求 grt,xg_{rt,x}grt,x​，在 rtrtrt 点分树子树里的每个点 kkk 维护一个 vector，表示 kkk 的子树没有被炸到的点，并按照其与 kkk 的距离从小到大排序。

然后直接从小到大枚举初始长度，同时维护一个队列表示新炸到的点，如果队列非空就拿出队首，枚举它炸到的下一个点的 LCA，在 LCA 的 vector 里从前往后枚举还没被炸到的点更新即可。

这部分时间复杂度是 O(nlog⁡2n)O(n\log^2n)O(nlog2n)。

再求 frt,xf_{rt,x}frt,x​。这里先求出从 xxx 开始第一次炸到 rtrtrt 最大剩余长度，枚举 xxx 在炸到 rtrtrt 之前炸到的最后一个点 yyy，由于 xxx 和 yyy 的 LCA 在 rtrtrt 的子树内，就转化为了已经求出来的 dp 值了。

具体地，设枚举的 LCA 是 kkk，则如果 fk,x≥gk,xf_{k,x}\geq g_{k,x}fk,x​≥gk,x​ 就说明可以让 disk,x+disk,ydis_{k,x}+dis_{k,y}disk,x​+disk,y​ 更新 frt,xf_{rt,x}frt,x​，这个可以双指针处理。

求出第一次炸到的结果后，利用新求出来的 grt,xg_{rt,x}grt,x​ 再双指针算即可。

这部分时间复杂度也是 O(nlog⁡2n)O(n\log^2n)O(nlog2n)。

现在求出了每个子树里的 dp 结果了，由于 xxx 能炸到 yyy 的条件是存在一个 rtrtrt，使得 frt,x≥grt,yf_{rt,x}\geq g_{rt,y}frt,x​≥grt,y​，这个 rtrtrt 不唯一，直接枚举 rtrtrt 会算重。

我们钦定 xxx 和 yyy 在 LCA 处计算，但是它们跳到的深度最浅的地方不一定是 LCA，所以还需要修改 dp 状态。

设 frt,xf_{rt,x}frt,x​ 表示从 xxx 炸到 rtrtrt 的最大剩余长度（可以炸到整棵树），grt,xg_{rt,x}grt,x​ 表示要想从 rtrtrt 炸到 xxx 的最小初始剩余长度（可以炸到整棵树）。

对于整棵点分树的根的 dp 数组已经通过刚才的过程得到了，考虑从上往下转移。

假设已经求出当前 rtrtrt 的所有祖先 rt′rt'rt′ 的 dp 数组。

先求新的 frt,xf_{rt,x}frt,x​。枚举 xxx 跳到 rt 之前的最后一个点 yyy，设经过的深度最浅的 LCA rt′rt'rt′。那么在 rt′rt'rt′ 的子树内 xxx 能跳到 yyy 的条件是 frt′,x≥grt′,yf_{rt',x}\geq g_{rt',y}frt′,x​≥grt′,y​，满足了这个条件即可对 frt,xf_{rt,x}frt,x​ 造成 ry−disy,rtr_y-dis_{y,rt}ry​−disy,rt​ 的贡献。

这个贡献可以在 rt′rt'rt′ 处处理，但是由于 yyy 和 rtrtrt 的 LCA 不固定，所以需要对于每个可能的 LCA kkk 维护出 ry−disk,xr_y-dis_{k,x}ry​−disk,x​ 的最优值，更新 frt,xf_{rt,x}frt,x​ 时再枚举 rtrtrt 的祖先即可。

这部分时间复杂度是 O(nlog⁡3n)O(n\log^3n)O(nlog3n)。

最后求 grt,xg_{rt,x}grt,x​。枚举 rtrtrt 跳到的第一个点 yyy，设最终跳到 xxx 的最浅点是 rt′rt'rt′，则 yyy 能对 grt,xg_{rt,x}grt,x​ 造成贡献的条件为 frt′,y≥grt′,xf_{rt',y}\geq g_{rt',x}frt′,y​≥grt′,x​，贡献为 disrt,ydis_{rt,y}disrt,y​。

跟求 fff 的做法一样在可能的 LCA(rt,y)LCA(rt,y)LCA(rt,y) 处维护 disk,ydis_{k,y}disk,y​ 的最优值即可。

这部分时间复杂度是 O(nlog⁡3n)O(n\log^3n)O(nlog3n)。

总的时间复杂度是：O(nlog⁡3n)O(n\log^3n)O(nlog3n)。
