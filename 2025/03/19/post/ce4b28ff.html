P11677 [USACO25JAN] Shock Wave P 题解

Description

Bessie 正在试验一种能够产生巨大冲击波的强大的蹄部植入物。她有 NNN（2≤N≤1052 \leq N \leq 10^52≤N≤105）块砖块排开在面前，分别需要至少 p0,p1,…,pN−1p_0,p_1,\dots,p_{N-1}p0​,p1​,…,pN−1​ 的力量才能击破（0≤pi≤10180 \leq p_i \leq 10^{18}0≤pi​≤1018）。

Bessie 可以通过击打特定的砖块来施加力量，但由于她的植入物的奇特性质，它不会对她所击打的那块砖块施加任何力量。相反，如果她选择击打砖块 xxx 一次，其中 xxx 是一个 [0,N−1][0,N-1][0,N−1] 范围内的整数，对所有在 [0,N−1][0,N-1][0,N−1] 范围内的整数 iii，它将对砖块 iii 施加 ∣i−x∣|i-x|∣i−x∣ 的力量。同时这个力量是累积的，因此对一块砖块施加两次 222 的力量将对该砖块施加总共 444 的力量。

请求出击破所有砖块所需要的最少击打次数。

∑N≤5×105\sum N\leq 5\times 10^5∑N≤5×105。

Solution

首先观察到 111 和 nnn 放到一起是很强的，所以如果存在两次操作分别在 2≤x≤y≤n−12\leq x\leq y\leq n-12≤x≤y≤n−1，则让其分别变为 x−1x-1x−1 和 y+1y+1y+1 一定更优。

所以最优方案一定满足只操作 111 和 nnn，或者操作 111 和 nnn，并在中间某个位置 kkk 操作一次。

不妨设 111 操作了 xxx 次，nnn 操作了 yyy 次，并枚举中间的操作位置 kkk。

则需要满足 ∀i∈[1,n],x⋅(i−1)+y⋅(n−i)+∣i−k∣≥pi\forall i\in[1,n],x\cdot(i-1)+y\cdot(n-i)+|i-k|\geq p_i∀i∈[1,n],x⋅(i−1)+y⋅(n−i)+∣i−k∣≥pi​。

考虑枚举 s=x+ys=x+ys=x+y，则可以得到不等式：(i−1)x+(n−i)(s−x)≥pi−∣i−k∣(i-1)x+(n-i)(s-x)\geq p_i-|i-k|(i−1)x+(n−i)(s−x)≥pi​−∣i−k∣，所以 (2i−n−1)x≥pi−∣i−k∣−(n−i)s(2i-n-1)x\geq p_i-|i-k|-(n-i)s(2i−n−1)x≥pi​−∣i−k∣−(n−i)s。

只要解出这 nnn 个不等式解的交即可，暴力做是 O(n2log⁡V)O(n^2\log V)O(n2logV)。

注意到在 kkk 移动的过程中，第 iii 个方程对应的解只会变化 O(n2i−n−1)O\left(\frac{n}{2i-n-1}\right)O(2i−n−1n​) 次，这是个调和级数的式子，所以总变化量为 O(nlog⁡n)O(n\log n)O(nlogn)，求出这些变化点并更新即可做到 O(nlog⁡nlog⁡V)O(n\log n\log V)O(nlognlogV)。

还是过不了。

考虑先求出中间位置没有操作的答案 resresres，这部分可做到 O(nlog⁡V)O(n\log V)O(nlogV)。由于一次 111 操作一次 nnn 操作一定优于一次中间操作，所以中间操作得到的答案最小为 res−1res-1res−1，只 check 这一个答案即可。

时间复杂度：O(nlog⁡V)O(n\log V)O(nlogV)。
