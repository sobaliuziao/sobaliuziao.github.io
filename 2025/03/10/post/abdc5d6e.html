P11835 [省选联考 2025] 封印 题解

Description

在一次探险中，小 H 发现了一个古老的封印。封印的本体是一个长度为 nnn 的序列 A=[a1,a2,…,an]A = [a_1, a_2, \ldots, a_n]A=[a1​,a2​,…,an​]。初始，每个元素都是 111 至 mmm 间的正整数。

设 ∣A∣|A|∣A∣ 表示序列 AAA 的长度，小 H 可以对序列进行以下修改:

  1. 选择序列 AAA 的某个严格前缀最大值元素 asa_sas​，即选择 1≤s≤∣A∣1 \leq s \leq |A|1≤s≤∣A∣ 满足 ∀1≤j<s,as>aj\forall 1 \leq j < s, a_s > a_j∀1≤j<s,as​>aj​，特别地，a1a_1a1​ 总是序列 AAA 的严格前缀最大值;
  2. 若 as≠1a_s \neq 1as​=1，将 (as−1)(a_s - 1)(as​−1) 插入序列 AAA 的尾端;
  3. 删去序列 AAA 的前 sss 个元素。

考虑如下例子：在 A=[1,3,2,3,4]A = [1, 3, 2, 3, 4]A=[1,3,2,3,4] 时，

  • 小 H 可以选择 s=1s = 1s=1，此时修改后的序列变为 [3,2,3,4][3, 2, 3, 4][3,2,3,4];
  • 小 H 可以选择 s=2s = 2s=2，此时修改后的序列变为 [2,3,4,2][2, 3, 4, 2][2,3,4,2];
  • 小 H 不能选择 s=4s = 4s=4，因为 a2=a4=3a_2 = a_4 = 3a2​=a4​=3，这意味着 a4a_4a4​ 并非严格前缀最大值。

小 H 可以进行任意多次修改操作，也可以不进行任何修改。为了解开封印，小 H 想知道：通过以上修改操作，他可以得到多少种不同的非空序列。

认为两个序列 A=[a1,…,an]A = [a_1, \ldots, a_n]A=[a1​,…,an​] 和 B=[b1,…,bm]B = [b_1, \ldots, b_m]B=[b1​,…,bm​] 不同，当且仅当 n≠mn \neq mn=m 或 ∃1≤i≤min⁡{n,m}\exists 1 \leq i \leq \min\{n, m\}∃1≤i≤min{n,m}，ai≠bia_i\neq b_iai​=bi​

由于答案可能很大，你只需告诉小 H 答案对 998 244 353998\,244\,353998244353 取模后的结果。

Solution

设操作次数最多的数的操作次数为轮数，容易发现不同轮之间的状态一定不会互相影响，因为最大值一定不相同。

注意到第二轮及以后的操作剩下的数一定可以在第一轮的时候截取出来，后面就变为每次必须选择开头操作的问题，所以考虑把第一轮和第二轮及以后的方案分开算。

首先是第二轮及以后的贡献。

先选择一个子集 SSS 表示方案由 SSS 中的数操作后构成，SSS 需要满足 aSia_{S_i}aSi​​ 为 aSi−1+1a_{S_{i-1}+1}aSi−1​+1​ 到 aSia_{S_i}aSi​​ 的严格前缀最大值，且 aS1a_{S_1}aS1​​ 必须比 aS∣S∣a_{S_{|S|}}aS∣S∣​​ 之后的数加一还大。

可以证明只要满足这个条件，不同的集合 SSS 算出的方案一定不重。

证明

显然 SSS 一定包含全局最大值，那么如果存在两个集合 S1,S2S_1,S_2S1​,S2​ 存在某个循环序列重复了，可以根据最大值的个数和位置得知它们操作的总次数  mod ∣S1∣\bmod |S_1|mod∣S1​∣ 一定相等。

根据这个就可以得知两个集合每个位置的值一一相等，所以 S1S_1S1​ 和 S2S_2S2​ 每个位置也一定一一对应。

不妨设最小值的位置是 ppp，则贡献为 (min⁡−2)⋅∣S∣+p(\min-2)\cdot |S|+p(min−2)⋅∣S∣+p，而把最小值删掉后的贡献会被其它集合算到。

但是这样做有 corner case，在 2 1 1 这组数据下删掉任何数都是不合法的。

考虑什么样的情况不会被算到。

容易发现 p+1∼∣S∣p+1\sim |S|p+1∼∣S∣ 一定都是最小值且第一个一定是最小值加一，否则把最右边的最小值删掉即可合法。

同时 1∼p−11\sim p-11∼p−1 都是最小值加一，否则选择第一个不是最小值加一的删掉也能合法。

所以 corner case 一定形如 {min⁡+1,min⁡+1,…,min⁡,min⁡}\{\min+1,\min+1,\ldots,\min,\min\}{min+1,min+1,…,min,min}，这部分有额外的 ∣S∣−1|S|-1∣S∣−1 的贡献。

按照上面的做法可得到一个 O(2nn)O(2^nn)O(2nn) 的做法，优化就枚举第一个最小值然后 dp 即可。

然后是第一轮的贡献。

同样是对选出的子集计数，先给出做法：

  1. 选择第一个 111 之后就一直选 111。
  2. 不能第一个选 222 且最后一个选序列末尾的 111。

不满足上面两个条件一定是不合法的，因为一定存在一种方案能够选择更少的数且方案一样。

下面是满足这两个条件后不会算重的不严谨感性证明。

证明

设全局最大值为 mxmxmx。

同样是通过最大值定位，对于一种方案，如果里面存在 mxmxmx，则原序列上的最后一个 mxmxmx 一定对应方案内的最后一个 mxmxmx，所以可以根据此得到最后一个选的数的位置，也就唯一确定了一种选择。

如果不存在 mxmxmx，说明每个 mxmxmx 都被选了，那么把新序列上最后一个 mx−1mx-1mx−1 一定对应原序列上的最后一个 mxmxmx，也就能够得到原序列每个 mxmxmx 对应的位置。考虑把原序列第一个 mxmxmx 到最后一个 mxmxmx 之间的数全部删掉，方案里的第一个 mx−1mx-1mx−1 到最后一个 mx−1mx-1mx−1 也删掉后就归纳了一个规模更小的问题。

对这个直接 dp 即可做到 O(n2)O(n^2)O(n2)。

时间复杂度：O(n2)O(n^2)O(n2)。
