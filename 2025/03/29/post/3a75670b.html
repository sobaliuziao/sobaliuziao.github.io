QOJ #10042. Scheduling 题解

Description

给定 nnn 个二元组 (li,ri)(l_i,r_i)(li​,ri​)，请你构造一个长度为 nnn 的序列 aaa，满足：

  • ∀1≤i≤n\forall 1\le i\le n∀1≤i≤n，li≤ai≤ril_i\le a_i\le r_ili​≤ai​≤ri​；
  • ∀1≤i<j≤n\forall 1\le i<j\le n∀1≤i<j≤n，∣ai−aj∣≥2|a_i-a_j|\ge2∣ai​−aj​∣≥2。

有 TTT 组数据。

1≤T≤100,1≤∑n≤2×105,1≤li≤ri≤1061\le T\le 100,1\le \sum n\le 2\times 10^5,1\le l_i\le r_i\le 10^61≤T≤100,1≤∑n≤2×105,1≤li​≤ri​≤106。

Solution

首先如果只要求互不相同就是个经典的贪心，对区间按照 rrr 排序，每次选择 ≥li\geq l_i≥li​ 的最小的数选。

但是这里显然不能这么做。考虑通过构造候选集合，来转化成上面的那个贪心。

即构造一个序列 b1,b2,…,bmb_1,b_2,\ldots,b_mb1​,b2​,…,bm​，满足 ∀1≤i<j≤m,∣bi−bj∣≥2\forall 1\leq i<j\leq m,|b_i-b_j|\geq 2∀1≤i<j≤m,∣bi​−bj​∣≥2 且满足最终的答案都在这里面选。

注意到如果给定 bbb 序列，这就是个单点匹配区间的问题，可以用 Hall 定理判断有无解。

所以考虑 Hall 定理。

设 F(l,r)F(l,r)F(l,r) 表示包含于 [l,r][l,r][l,r] 的询问区间数，G(l,r)=r−l+1−2⋅F(l,r)G(l,r)=r-l+1-2\cdot F(l,r)G(l,r)=r−l+1−2⋅F(l,r)，可以用线段树+扫描线维护 G(l,r)G(l,r)G(l,r) 的值。

那么如果存在 l,rl,rl,r，使得 G(l,r)≤−2G(l,r)\leq -2G(l,r)≤−2，那么无论怎么填都不能满足这个区间的限制，也就是无解。

如果 G(l,r)=−1G(l,r)=-1G(l,r)=−1，那么这个区间一定是填形如 101010110101011010101 这样一个 111 一个 000 交错的形式。

其余的先不管。

把所有满足 G(l,r)=−1G(l,r)=-1G(l,r)=−1 的区间拿出来后，已经可以确定一部分位置的答案了，把这些已知的为 111 的位置 c1,c2,…,ckc_1,c_2,\ldots,c_kc1​,c2​,…,ck​ 拿出来后容易发现不同区间之间的填法基本上是独立的，考虑从前往后对于 [ci+1,ci+1−1][c_i+1,c_{i+1}-1][ci​+1,ci+1​−1] 分别做。

如果 (ci+1−ci) mod 2=0(c_{i+1}-c_i)\bmod 2=0(ci+1​−ci​)mod2=0，那么这个区间一定填的是 010101…010010101\ldots 010010101…010，其余的一定不优。

如果 (ci+1−ci) mod 2=1(c_{i+1}-c_i)\bmod 2=1(ci+1​−ci​)mod2=1，注意到现在不能像上面那样去完全交错填了，即一定存在一个 ggg，满足 ggg 和 g+1g+1g+1 都是 000，可以发现 [ci,g−1][c_i,g-1][ci​,g−1] 和 [g+2,ci+1][g+2,c_{i+1}][g+2,ci+1​] 都交错着填一定更优。

由于 ggg 越小对于后面的区间一定更优，所以只需要对于当前区间找到最小的能够满足所有 r≤ci+1r\leq c_{i+1}r≤ci+1​ 的区间的限制的 ggg 即可。

设 H(l,r)H(l,r)H(l,r) 表示 [l,r]没有确定答案的点数+2×([l,r]中确定的1的个数−包含于[l,r]的区间数)[l,r] 没有确定答案的点数+2\times \left([l,r] 中确定的 1 的个数-包含于 [l,r] 的区间数\right)[l,r]没有确定答案的点数+2×([l,r]中确定的1的个数−包含于[l,r]的区间数)，容易发现所有没有确定的点一定都在 (ci,ci+1)(c_i,c_{i+1})(ci​,ci+1​) 内。

考虑从前往后扫右端点 rrr，找到满足 H(l,r)H(l,r)H(l,r) 最小的最小的 lll。

  • 如果 H(l,r)<0H(l,r)<0H(l,r)<0，显然 l≤cil\leq c_il≤ci​，否则 lll 一定会被加到 ccc 数组里。由于 ci+1c_i+1ci​+1 一定填 000，所以无论如何也不能满足 [l,r][l,r][l,r] 的限制。

  • 如果 H(l,r)=0H(l,r)=0H(l,r)=0，则 ggg 和 g+1g+1g+1 出现在 [l,r][l,r][l,r] 里会让 H(l,r)H(l,r)H(l,r) 减为负数，不满足条件，给 [l,r][l,r][l,r] 打上标记表示 ggg 不能出现在里面。

  • 如果 H(l,r)>0H(l,r)>0H(l,r)>0，则 ggg 在哪里 [l,r][l,r][l,r] 都能满足条件，不管它。

最后 (ci,ci+1)(c_i,c_{i+1})(ci​,ci+1​) 里找最小的与 ci+1c_{i+1}ci+1​ 奇偶性相同且没被打上标记的位置就是 ggg，然后更新线段树。

注意多组数据 ∑ri\sum r_i∑ri​ 是没有限制的，所以需要离散化。具体的做法是按照 lll 排序，然后每次找到 ≥li\geq l_i≥li​ 的 333 没选的位置加进去，最后对 l,rl,rl,r 分别二分找到对应取值，再做上面的东西。

时间复杂度：O(nlog⁡n)O(n\log n)O(nlogn)。
