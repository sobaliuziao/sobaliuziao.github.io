P9331 [JOISC 2023] 护照 题解

Description

护照是旅行家进入他国时使用的证件。

在一个星球上有 NNN 个国家，从 111 到 NNN 编号。每个国家都签发一种护照。当旅行家获得由国家i (1≤i≤N)i \ (1 \le i \le N)i (1≤i≤N) 签发的护照后，他能够进入国家 Li,Li+1,…,RiL_i, L_{i + 1}, \dots, R_iLi​,Li+1​,…,Ri​。这里保证旅行家能够进入其签证的签发国。形式上地说, Li≤i≤RiL_i \le i \le R_iLi​≤i≤Ri​ 必然成立。

你有一个爱旅行的朋友。即使他奢望能环游世界，但他最初一种护照也没有。因此，他想通过一下重复以下两项行为来环游这 NNN 个国家。

  • 获得他当前所在国家签发的护照。
  • 用他现有的护照进入某个国家。

知道他的计划后，你想知道这个计划的是否可行，和如果可行的话，他最少需要的护照数量。因为你并不清楚他现在身处何国，所以你预测了 QQQ 个他可能正居住在那的国家 X1,X2,…,XQX_1, X_2, \dots, X_QX1​,X2​,…,XQ​。

现在给定各国护照的信息 Li,RiL_i, R_iLi​,Ri​ 和他可能居住的 QQQ 个国家，您需要写一个程序，对于每一个可能居住的国家，判断他是否可能环游这 NNN 个国家，如果可能的话，计算出他需要的最少护照种数。

2≤N≤2×1052 \le N \le 2 \times 10 ^ 52≤N≤2×105，1≤Li≤i≤Ri≤N1 \le L_i \le i \le R_i \le N1≤Li​≤i≤Ri​≤N。

Solution

首先能到的国家一定是一段区间，如果设当前区间为 [L,R][L,R][L,R]，则每次相当于是选择一个 i∈[L,R]i\in [L,R]i∈[L,R]，让 L←min⁡{L,li},R←max⁡{R,ri}L\leftarrow\min\{L,l_i\},R\leftarrow\max\{R,r_i\}L←min{L,li​},R←max{R,ri​}。

然后有个观察是在当前的 [L,R][L,R][L,R] 里最多选择两个区间进行拓展，并且拓展后就再也不会选择 [L,R][L,R][L,R] 内的区间了，否则提前选一定更优。

设 fif_ifi​ 表示区间为 [li,ri][l_i,r_i][li​,ri​] 的最小答案。

如果当前只选一个区间，则 fi←fj+1 (j∈[li,ri])f_i\leftarrow f_j+1\ (j\in[l_i,r_i])fi​←fj​+1 (j∈[li​,ri​])。

如果选择两个区间 [lx,rx],[ly,ry][l_x,r_x],[l_y,r_y][lx​,rx​],[ly​,ry​]，则一定满足 lx≤li,ry≥ril_x\leq l_i,r_y\geq r_ilx​≤li​,ry​≥ri​，此时由于 [li,ri][l_i,r_i][li​,ri​] 不会再选了，那么 xxx 和 yyy 一定是一个拓展左端点到 111，另一个是拓展右端点到 nnn，否则一个在拓展的过程中一定会拓展到另一个。

这样的话如果求出 dis1idis1_idis1i​ 表示将 [li,ri][l_i,r_i][li​,ri​] 左端点拓展到 111 的答案，dis2idis2_idis2i​ 表示将右端点拓展到 nnn 的答案，就可以让 fi←dis1x+dis2y+1f_i\leftarrow dis1_x+dis2_y+1fi​←dis1x​+dis2y​+1 即可。

考虑怎么求出 dis1idis1_idis1i​ 和 dis2idis2_idis2i​。下面只考虑求 dis1idis1_idis1i​。

由于此时只需要单方向拓展，所以只要让 dis1i←dis1j+1 (j∈[li,ri])dis1_i\leftarrow dis1_j+1\ (j\in [l_i,r_i])dis1i​←dis1j​+1 (j∈[li​,ri​]) 即可。

两部分都可以用线段树优化建图和 Dijkstra 求。

时间复杂度：O(nlog⁡2n)O(n\log^2 n)O(nlog2n)。
