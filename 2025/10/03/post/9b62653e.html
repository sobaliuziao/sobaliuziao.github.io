Description

JOI 美术馆计划近期举办一场绘画展览。馆方拥有编号为 111 至 NNN 的 NNN 幅画作，其中画作 iii（1≤i≤N1 \leq i \leq N1≤i≤N）的美观值为 AiA_iAi​。在展览中这些画作将排成一行展示，但具体排列顺序尚未确定。

共有 MMM 家杂志将对展览进行报道。这些杂志按影响力从大到小依次编号为 111 至 MMM。每家杂志将发布展览中某一连续段画作的摄影照片。具体来说，杂志 jjj（1≤j≤M1 \leq j \leq M1≤j≤M）将发布排列中从左数第 Lj,Lj+1,…,RjL_j, L_j + 1, \ldots, R_jLj​,Lj​+1,…,Rj​ 幅画作的照片。杂志 jjj（1≤j≤M1 \leq j \leq M1≤j≤M）报道的吸引力定义为该杂志所覆盖画作的最大美观值。

JOI 君作为 JOI 美术馆的馆长，希望通过排列画作使得这些杂志的报道更具吸引力，从而吸引更多参观者。由于影响力更大的杂志能触达更多受众，他优先希望提升更具影响力杂志的报道吸引力。

具体而言，设 bjb_jbj​ 为杂志 jjj（1≤j≤M1 \leq j \leq M1≤j≤M）报道的吸引力，则 JOI 君希望排列画作，使得序列 b=(b1,b2,…,bM)b = (b_1, b_2, \ldots, b_M)b=(b1​,b2​,…,bM​) 的字典序最大化。

在这里，对于不同的数列 b=(b1,b2,…,bM)b = (b_1, b_2, \ldots, b_M)b=(b1​,b2​,…,bM​) 和 b′=(b1′,b2′,…,bM′)b' = (b'_1, b'_2, \ldots, b'_M)b′=(b1′​,b2′​,…,bM′​)，所谓“bbb 在字典序上大于 b′b'b′”，是指存在满足 bk≠bk′b_k \neq b'_kbk​=bk′​ 的最小下标 kkk（1≤k≤M1 \leq k \leq M1≤k≤M），且对于该 kkk 有 bk>bk′b_k > b'_kbk​>bk′​。

首先如果 f(S)f(S)f(S) 一直会增加的话 slisl_isli​ 和 srisr_isri​ 会很不好维护，所以考虑先二分找到一个极长的前缀使得这个前缀的 f(S)f(S)f(S) 不超过 limlimlim。

先维护出这个前缀的区间构成的 [sli,sri][sl_i,sr_i][sli​,sri​]，我们用优先队列维护与某个区间 [sli,sri][sl_i,sr_i][sli​,sri​] 的相交的编号最小的区间。每次弹出队首并暴力更新 slisl_isli​ 和 srisr_isri​，由于 slisl_isli​ 只会变大，srisr_isri​ 只会变小，而分别总共只有 O(c)O(c)O(c) 种取值，所以 [sli,sri][sl_i,sr_i][sli​,sri​] 的历史总变化量为 O(c)O(c)O(c)。如果某个 [slj,srj][sl_j,sr_j][slj​,srj​] 被更新了，就再往优先队列里加入一个与当前的 [slj,srj][sl_j,sr_j][slj​,srj​] 相交的最小区间。
