CF2152H2 Victorious Coloring (Hard Version) 题解

Description

给定一棵有 nnn 个顶点的树，每个顶点编号为 111 到 nnn。每条边都被赋予一个正整数权值 w1,w2,…,wn−1w_1, w_2, \ldots, w_{n-1}w1​,w2​,…,wn−1​。

一种“胜利染色”指的是将所有顶点染成红色或黄色两种颜色，其中必须至少有一个顶点染成红色（这象征着队伍 T1 的象征）。

设对每个顶点分配了一个非负整数权值 x1,x2,…,xnx_1, x_2, \ldots, x_nx1​,x2​,…,xn​。胜利染色的代价被定义为：所有红色顶点权值之和，加上所有连接不同颜色顶点（即红色和黄色）之间的边的权值之和。定义 f([x1,x2,…,xn])f([x_1, x_2, \ldots, x_n])f([x1​,x2​,…,xn​]) 为所有胜利染色下可能的最小代价。

Gumayusi 考虑了在给定序列 x1,x2,…,xnx_1, x_2, \ldots, x_nx1​,x2​,…,xn​ 时计算 f([x1,x2,…,xn])f([x_1, x_2, \ldots, x_n])f([x1​,x2​,…,xn​]) 的问题。但对他而言这个问题太简单了，于是他改进了这个问题：给定一个整数 lll，求一组非负整数顶点权值 [x1,x2,…,xn][x_1, x_2, \ldots, x_n][x1​,x2​,…,xn​]，使得 f([x1,x2,…,xn])≥lf([x_1, x_2, \ldots, x_n]) \ge lf([x1​,x2​,…,xn​])≥l 且顶点权值总和 ∑i=1nxi\sum_{i=1}^n x_i∑i=1n​xi​ 最小。

Gumayusi 感到满意，但还存在一个严重问题——这个问题没有任何询问，对于任何不是“坏的”题目来说是不可接受的。因此，他给这个问题增加了询问。每给定一个 lll 作为询问，你需要输出相应的最小总顶点权值。

1≤n,q≤2.5×1051\leq n,q\leq 2.5\times 10^51≤n,q≤2.5×105。

Solution

设 g(S)g(S)g(S) 表示选择 SSS 点集内的点染红的边权代价和，那么问题实际上等价于选择一些互不相交的集合 S1,S2,…,SkS_1,S_2,\ldots,S_kS1​,S2​,…,Sk​，最大化 ∑(l−g(si))\sum(l-g(s_i))∑(l−g(si​))。

首先容易发现最优划分中 SSS 一定构成一个连通块，否则随便选择任意一个连通块 TTT 的 g(T)g(T)g(T) 值一定小于 g(S)g(S)g(S)，最终的结果也就更大。

还有一个结论是如果存在两条边 e1e_1e1​ 和 e2e_2e2​，满足 e1e_1e1​ 两个端点都在 SSS 中，e2e_2e2​ 恰有一个端点在 SSS 中，则一定满足 w(e1)>w(e2)w(e_1)>w(e_2)w(e1​)>w(e2​)。否则把 e1e_1e1​ 断掉会把 SSS 划分成两个集合 S1S_1S1​ 和 S2S_2S2​，选择不包含 e2e_2e2​ 的端点的那个集合，那么 ggg 值一定会至少减少 w(e2)−w(e1)≥0w(e_2)-w(e_1)\geq 0w(e2​)−w(e1​)≥0，矛盾。

注意到如果我们固定最优划分集合 SSS 邻域中边权最小的边是 eee 后，只会有至多两个集合满足条件！这是因为 eee 只有两个端点，这两个集合就是两边分别走边权大于 w(e)w(e)w(e) 的边后能走到的连通块。

由于这个很类似最大生成树，所以考虑建出边权从大到小的 kruskal 重构树。那么每次选择的集合一定构成一个子树。

每个子树的 ggg 值容易树上差分求，设 sus_usu​ 表示 uuu 选择子树的 ggg 值，fuf_ufu​ 表示 uuu 子树能选择的最大 ∑(k−su)\sum(k-s_u)∑(k−su​)。

容易得到转移：fu←max⁡(flsu+frsu,k−su)f_u\leftarrow \max(f_{ls_u}+f_{rs_u},k-s_u)fu​←max(flsu​​+frsu​​,k−su​)，直接转移是 O(nq)O(nq)O(nq) 的。

优化就考虑最终的答案一定是由 k⋅i+wk\cdot i+wk⋅i+w 的形式构成的，设 gu,ig_{u,i}gu,i​ 表示 uuu 的子树中系数为 iii 的最大 www 值。
